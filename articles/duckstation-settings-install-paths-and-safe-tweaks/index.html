Frequently asked questions

Should I use portable mode or a standard install?

Use portable mode when you want self contained folders for configs and saves across machines. Choose a standard install for single user desktops where OS paths and profiles stay consistent. Both work, but pick based on mobility and maintenance preferences.

What DuckStation settings are safe to change first?

Set a global preset, verify VSync and renderer selection, then test one title. If a tweak helps only one game, move it to a per game override. Avoid shader stacks or timing changes until you capture baseline performance and a log.

Where do I find logs to diagnose an error?

Check the configured log directory in settings, then reproduce the issue to create a fresh file. If the app crashes before writing logs, capture system level details with platform tools and note timestamps that align with your test.

How do I update without breaking my configuration?

Export current settings and memory cards, then install the new version to a test location first. Verify paths and launch a baseline game. If everything passes, move the updated build into place and keep the backup for rollback.

When should I reset to a clean baseline?

Reset when symptoms persist across titles, logs are inconclusive, or you cannot explain changes after updates. A clean baseline simplifies comparison and rules out mixed settings that hide the real cause of a problem.
