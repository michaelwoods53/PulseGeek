Frequently asked questions

Should I use Pacman or Flatpak for most apps?

Use Flatpak for everyday desktop apps to isolate changes and simplify updates. Reserve Pacman for system components or tools that must integrate with the base OS. Mixing both is fine when the purpose is clear and documented.

When do I adjust display scaling in Desktop Mode?

Adjust scaling before heavy setup so windows and dialogs remain reachable. Test cursor precision at window edges after changes, then save the layout. Recheck settings after docking or undocking to ensure persistence.

What is the safest way to prepare a new microSD?

Pick a format that matches your usage, label the volume, and run a short write and read test. Eject the card through the file manager before removal to prevent pending writes from corrupting data.

How do I know an update went well?

Confirm there are no unexpected removals, reopen a few common apps, and watch performance and temperature settle. Keep a short log of changes so you can compare behavior across restarts and revert if needed.

What should I check before transferring files over SSH?

Verify the device IP, confirm key permissions, and run a small test copy. After the transfer, compare sizes or open a sample file to validate integrity before deleting the source.
