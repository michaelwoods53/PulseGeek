Set Up an Xbox Controller in DuckStation

By Brian Rogers • Published January 18, 2026

Setting up an Xbox controller in DuckStation is straightforward once you choose the right input path and map controls with intention. This guide shows how to configure the controller, enable vibration, and tune analog response for PS1 games. If you follow the branching workflows, you can get reliable behavior on Windows, macOS, Linux, and Steam Deck while preserving per game flexibility for outliers that need different mappings.

Key takeaways

  • XInput usually provides the simplest Xbox controller experience in DuckStation.
  • Map DualShock analog mode only for games that expect it.
  • Calibrate deadzones before adjusting sensitivity curves for precise input.
  • Enable rumble and test intensity per device to avoid clipping.
  • Create per game profiles to handle analog to D pad compatibility gaps.

Frequently asked questions

Should I use XInput or DInput for an Xbox controller?

Use XInput when available because it provides consistent button indices and reliable rumble on Windows. Try DInput only if your platform or driver stack requires it and validate that button labels and vibration map correctly afterward.

Why does my controller work in Steam but not in DuckStation?

Steam Input can capture the device and present a virtual pad. Disable Steam Input for the app or test DuckStation launched outside Steam. If detection returns, re enable Steam Input and adjust pass through so the emulator receives inputs directly.

How do I fix drifting analog sticks in games?

Lower or raise the emulator deadzone until small movements register without unintended drift. Verify controller hardware is stable by testing in another title. Some games filter input internally, so apply per game overrides when the global setting is not sufficient.

Do all PS1 games support analog sticks?

No. Many early titles expect only digital input. Keep analog mode off for those games and use analog to D pad mapping when needed. Enable DualShock analog only for games that read sticks correctly to avoid conflicts with menus or movement.

Why is rumble weak or only on one side?

Driver layers or overlays can reduce intensity or route motors asymmetrically. Test each motor in the emulator, increase intensity slightly, and verify no second layer scales output. Update controller firmware and drivers if tests show inconsistent feedback.
