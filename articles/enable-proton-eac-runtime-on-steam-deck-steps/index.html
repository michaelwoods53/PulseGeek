Frequently asked questions

Do I need PROTON_EAC_RUNTIME for every EAC game?

No. Some EAC titles ship compatible components or use different initialization paths. Enable it per game only when the title requires it or shows missing runtime messages.

Where do I paste the launch option string on Steam Deck?

Open the game in Steam, select the gear icon, choose Properties, and paste the string into Launch Options for that specific title.

Which Proton version should I try first?

Start with Proton Experimental or the latest stable release. If issues persist, try a previously successful build noted in community reports for your specific game.

Can other launch flags break anti cheat initialization?

Yes. Some flags alter overlays, input, or hooks that anti cheat monitors. Remove non essential options and retest if integrity or untrusted module errors appear.

How do I confirm the runtime actually loaded?

Look for an EAC splash or status line and correlate timestamps with Proton logs. Successful runs typically show initialization without missing module or stub fallback messages.
