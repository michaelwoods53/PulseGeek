How to Set Up Multitap in DuckStation

By Brian Rogers • Published January 25, 2026

Yes, you can set up multitap in DuckStation by enabling a multitap device on one controller port and mapping additional controllers to the resulting pad slots. Most four-player PS1 titles expect a multitap on Port 2, though a few require Port 1. This guide shows how to pick the correct port quickly, map inputs that do not conflict, and verify the game sees each player before a match starts.

Key takeaways

  • Most four-player games expect the multitap assigned to controller Port 2.
  • Map each controller to a unique pad slot before launching the game.
  • Confirm recognition on the game’s multiplayer screen before starting play.
  • Switch ports if players are missing, then reload and retest in DuckStation.
  • Save per-game settings when different titles require different port choices.

Short answer and nuance

The fastest path is to enable a multitap on the correct DuckStation controller port, then map each controller to its own pad slot. Many four-player games read the adapter from Port 2, while a minority prefer Port 1, so begin with Port 2 for a quick win. After toggling the adapter, assign P1 through P4 bindings so inputs never overlap. A clean binding prevents ghost inputs and lets games enumerate pads predictably. If you launch a title and see only two players, back out, switch the multitap to the other port, and relaunch the game menu. This two-step loop avoids deep menus and focuses on results you can measure.

Choosing Port 2 first works because numerous multiplayer menus scan that port’s pads before the primary controller. A simple rule of thumb is to try Port 2 for party racers and sports titles, then move to Port 1 if the lobby shows fewer than four pads. For games with a built-in controller test or setup screen, you can press Start on each controller to confirm enumeration order. If vibration or analog lights behave oddly, do a quick remap to clear duplicate buttons. That prevents one device from stealing focus and ensures player slots attach consistently across launches.

Pre-mapping controllers within DuckStation reduces friction because the emulator can present stable device IDs to the game. Bind each device, test directions and buttons, then name profiles so you can reuse them later without repeating work. When players rotate, load each person’s preferred profile and keep pad slots aligned to P1 through P4. If you are on Windows using Steam Input, disable overlapping mappings or set it to passthrough to avoid double-input. On macOS or Linux, verify permissions and that only one input backend feeds DuckStation. Stable input paths mean fewer surprises when multitap is toggled.

When it applies vs when it does not

Multitap applies when a PS1 title advertises three or four local players or includes a controller setup that lists pads beyond two. Sports, kart racers, and party compilations often include the extra slots. The signal you want is a multiplayer menu that shows P1 through P4 or a join prompt for more than two people. If the lobby accepts Start from three or four controllers, your port choice is correct. When the game offers only two slots regardless of port, multitap is likely not supported. Recognizing that early saves time and avoids chasing the wrong setting.

Some games display four-player modes that activate only on specific tracks or rule sets, which can mislead testing if you stop at the first menu. Enter the exact multiplayer mode and navigate to its controller assignment screen to confirm behavior. When support is partial, using the wrong port can hide extra players until a deep sub-menu is selected. If switching ports still yields two pads, try removing analog mode or remapping to basic buttons to rule out input conflicts. The goal is to separate game design limitations from configuration mistakes and adjust only the necessary variable.

There are edge cases where multitap does nothing, even though the manual suggests multi-person play. Some titles use alternating turns with two pads rather than true simultaneous control, which the emulator cannot transform into four concurrent inputs. Others may require all controllers to be digital before they appear, so toggle analog off temporarily during detection. Finally, if you are routing through Steam Input or another layer, duplicated bindings can present as phantom pads that fight for focus. In that case, consolidate to a single input path and retest within the actual multiplayer screen for clarity.

Frequently asked questions

Which port should I enable for the multitap in DuckStation?

Start with Port 2 because many four-player games look there first. If only two pads appear in the lobby, switch to Port 1, relaunch the game, and test the join prompts again.

Do all PS1 games support a multitap?

No. Some games only support two simultaneous players or alternate turns. If a multiplayer screen never shows more than two pads after trying both ports, the title likely lacks multitap support.

How do I stop players sharing the same inputs?

Bind each controller to a unique pad slot and avoid duplicate buttons. Save the working profiles, then reload them before play so each device maps to a separate player position.

Can Steam Input or other layers break multitap detection?

Yes. If multiple layers translate inputs, devices can overlap and confuse the game. Use a single input path or set the storefront layer to passthrough, then remap inside the emulator.

Should I use analog mode with multitap games?

Only if the game supports it. If pads fail to appear, try disabling analog temporarily during detection, then re-enable after the lobby recognizes all player slots.
