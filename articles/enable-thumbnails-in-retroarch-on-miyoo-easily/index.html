Enable Thumbnails in RetroArch on Miyoo Easily

By Jared Butler • Published February 16, 2026

Our goal is to enable thumbnails in RetroArch on Miyoo, tie artwork to playlists, and avoid slow menus. You will set correct directories, fetch thumbnail packs, and confirm that images resolve for the games you already indexed. This walkthrough assumes a standard Miyoo SD layout with RetroArch installed and working, plus basic access to the RetroArch menu. If you are still building your base install or configuring storage paths, consider reviewing a full setup first, then return to thumbnail configuration so the process flows smoothly.

Key takeaways

  • Set the thumbnails directory to a writable path on the SD card.
  • Match playlist names to the naming convention used by thumbnail packs.
  • Prefer smaller image variants to keep the Miyoo menu responsive.
  • Verify artwork appears per entry by toggling left and right panels.
  • Rebuild playlists after renaming ROMs to restore thumbnail links.

Plan the work

Start by defining what “thumbnails working” means for your Miyoo device, because scope determines effort and risk. A practical target is box art and snaps for platforms you actually play, not your entire library. On handheld hardware, downloading every pack can slow menus and consume storage unexpectedly. As a rule of thumb, begin with one or two systems and confirm performance before expanding. If you use both boxart and title screens, choose one priority set first so you can measure the effect. Planning smaller test batches gives you faster feedback and prevents confusion from misaligned playlist names across many systems.

Next, choose whether to fetch thumbnails from within RetroArch or import prebuilt packs. The in-app downloader is convenient and aligns naming automatically, but it needs a stable network and can be slow. Prebuilt packs copy quickly and work offline, but you must match folder names and playlist titles precisely. Decide early which route fits your constraints and time. For example, if your Miyoo often stays offline, favor packs stored on the SD card. If you are unsure about naming conventions or want the easiest first success, start with the built-in downloader for one playlist.

Finally, verify paths and storage space so the work does not stall halfway. Thumbnails live under a configured thumbnails directory, and playlists must reference games consistently. If the SD card lacks free space or the path points to internal storage, you may see blank panels or intermittent artwork. Aim to keep a few hundred megabytes free for the first tests. Check that your ROMs and playlists use stable names, since renaming games after art is downloaded breaks links. Confirm you can access the RetroArch menu and that menu widgets are visible so you can see artwork panels during validation.

Prepare environment

Set the thumbnails directory first so RetroArch knows where to read and write artwork. In Settings then Directories, find Thumbnails and point it to the SD card path used by your RetroArch build, commonly a thumbnails folder alongside your playlists. Using the SD card keeps writes off internal storage and makes backups simple. If you are unsure of the exact path conventions on Miyoo, confirm by checking where your playlists live and mirroring that root. A predictable path prevents mixed locations that lead to missing images. This step matters because both the downloader and manual packs rely on the directory being correct.

Enable the menu panels that display artwork so you can see results while you configure. Under Settings then User Interface and Menu, ensure thumbnail visibility options are on, such as left or right thumbnail panels. On Miyoo hardware, rendering two panels can add overhead, so start with a single panel to confirm responsiveness. You can later enable both boxart and title screen panels if performance remains smooth. Also verify the menu driver is the one you prefer. Simple menu drivers often scroll faster on handhelds, which makes thumbnail browsing feel fluid once artwork appears.

If your setup prefers editing config files, you can set key thumbnail flags directly in retroarch.cfg. This helps when the UI is constrained or certain builds hide options. The example below shows typical lines to review and change. Expect the outcome to be the same as adjusting the menu: thumbnails save to the SD path, at least one panel shows images, and auto download is allowed when needed. Always back up your config before editing, and reboot RetroArch after changes so the settings load cleanly.

Execute steps

With paths and panels ready, fetch artwork for a single playlist to validate your setup. Using the RetroArch interface, open a playlist, press the thumbnail action for a game, then choose to download missing thumbnails for that list. This leverages RetroArch’s naming rules to match box art and snaps. The first pass may take a few minutes depending on the size of your playlist and network speed. If thumbnails begin appearing for some entries but not others, that is normal. Missing art can reflect unavailable images upstream or mismatched titles. You can correct those later by adjusting names or adding manual images.

If you prefer offline packs, copy the correct platform folder into your thumbnails directory and keep the subfolders Boxarts, Snaps, and Titles intact. Match the folder name to the playlist name, including letter case and spaces. A mismatch prevents RetroArch from finding images even when files exist. Test with five to ten ROMs whose names mirror the pack’s expectations. If images do not appear, inspect sample filenames and compare with the playlist’s entries. When differences are small, creating a few renamed copies helps you confirm the mapping before bulk moves.

Before moving on, check that playlist spelling aligns with your ROM directory labels and any scanning methods you used. If your earlier scan created a differently named playlist than your art pack, rename either the playlist or the folder under thumbnails so they match exactly. This detail often explains partial success after a download. Once your first list is stable, repeat the process for another system. Spacing the work across sessions prevents buildup of large downloads and lets you observe menu speed. Validate results

Validation begins by browsing the playlist you just updated and scanning several entries. Confirm that at least one panel shows artwork consistently. If some items are missing, pick a representative ROM and compare its file name to the art file naming pattern inside the thumbnail folder. Small discrepancies like region tags or punctuation often cause misses. Try renaming a single art file to mirror the playlist entry as a quick test. If it appears immediately, extend the correction to others. This approach avoids incorrect assumptions about broken downloads and saves time before attempting larger rescans.

Next, assess responsiveness while thumbnails load. Scroll through a long list and observe whether navigation stutters or lags. On Miyoo devices, larger images can slow the menu, especially if two panels are enabled. If you notice sluggish behavior, disable one panel or prioritize the smallest image type used in your pack. For example, choose snaps over full-resolution box art when smooth scrolling matters more than aesthetics. The ideal balance keeps browsing immediate while still giving enough visual cues to identify games quickly.

Finally, re-open RetroArch after a cold start to ensure settings persist. Some builds store paths or UI toggles in multiple files, and changes may not stick if you exited abruptly. Power cycle, return to your playlist, and recheck a few entries. If the panels revert or thumbnails disappear, revisit your retroarch.cfg and look for another file that overrides it. At this point, consolidating your directory structure and keeping backups will make rollbacks simple. Troubleshoot and optimize

If thumbnails do not appear after downloads, investigate naming mismatches first because they cause the majority of misses. Compare a failing playlist entry to its expected art filename, including region markers and punctuation. When multiple entries are off, it may be faster to rebuild the playlist with a consistent naming scheme rather than editing art files individually. Rebuilding also helps if you recently moved ROMs. RetroArch tends to follow the names present at scan time, so changing directories without rescanning can sever the artwork link until the list is regenerated.

When the menu stutters, target image sizes and the number of panels. Disabling the secondary panel is the quickest win on Miyoo, followed by picking lighter artwork types where possible. Some packs include multiple sizes, and using smaller variants reduces memory usage. Avoid downloading every available image category for all systems. Broad sets create heavy IO on handheld storage. If you must keep both panels, reduce the number of systems with artwork enabled at once and focus on the ones you browse often. This prioritization returns noticeable speed without abandoning visuals entirely.

If your directory paths drifted over time, establish a clean structure so future updates stay predictable. Keep thumbnails, playlists, and ROMs on the SD card under stable root folders and avoid duplicating platform names. Back up directories before editing large batches so you can revert quickly. Consider adopting a standard map of cores, system, saves, and states for clarity, then mirror that organization for thumbnails and playlists. Having a consistent layout pays dividends during updates and migrations. If you eventually update RetroArch, recheck the directories to ensure defaults did not overwrite your custom paths, which can break artwork unexpectedly.

Frequently asked questions

Why do some games show art while others stay blank?

Most gaps come from naming mismatches or unavailable images. Compare a failing entry’s title to the art filename pattern in the thumbnails folder. Adjust the name or rebuild the playlist so entries match consistently.

Should I enable both thumbnail panels on Miyoo?

Start with one panel to gauge responsiveness. Two panels look nice but can slow scrolling on handheld hardware. If performance holds after testing, add the second panel and reassess menu speed.

Where should the thumbnails directory live?

Use the SD card so writes are consistent and backups are simple. Keep thumbnails near playlists under a stable root to avoid mixed paths that lead to missing images after updates.

Do I need to rescan after renaming ROMs?

Yes. Renaming ROMs changes the titles that playlists reference, which breaks links to existing artwork. Rebuild the playlist so names align again and thumbnails resolve for each entry.

Are offline thumbnail packs better than the downloader?

Packs are faster offline but require precise folder names. The downloader aligns names automatically but depends on a stable network and can take longer. Choose based on your connectivity and time.
