Where to Put ROMs in Onion OS

By Jordan Kelly • Published February 14, 2026

You will learn exactly where to put ROMs in Onion OS and how to confirm the system reads them properly. We assume a microSD prepared for your handheld, basic file management skills, and ROMs legally obtained. The walkthrough balances precision and safety so new users avoid rescans that waste time. Along the way, we will reference folder structure, naming choices, and artwork behavior so your library feels tidy from the start. If you already have files scattered across multiple cards, the steps still apply, you will just map and move deliberately to reduce surprises.

Key takeaways

  • Place ROMs under the correct system folder so Onion OS scans.
  • Use supported formats and keep archives consistent for faster indexing.
  • Validate with one small test game before moving a large library.
  • Fix missing entries by correcting paths, BIOS needs, or extensions.

Prepare environment

Prepare your microSD card and confirm the filesystem is supported by your device, because incompatible formats can truncate transfers or hide directories. Many handhelds read FAT32 widely, with file size limits that matter when handling disc-based ROMs. ExFAT supports larger files but can be sensitive on some firmware versions. If you are unsure, copy a small file, eject safely, and reinsert to confirm it persists. The modest test prevents larger transfers from failing silently. As a tradeoff, repartitioning later is possible but time consuming, so decide now if you will keep disc-based titles that exceed four gigabytes and plan format choice accordingly.

Gather a minimal set of ROMs and verify extensions are supported by the emulators included in Onion OS, because uncommon formats can be skipped during scans. Start with a couple of no-intro verified files to reduce bad dumps as a source of problems. If you intend to keep archives compressed, confirm whether the target core can read zip or 7z directly. If not, extract to the intended system folder and retest detection. The tradeoff is storage overhead against faster indexing and fewer runtime decompression issues. You can change direction later, but consistency during setup makes troubleshooting easier.

Execute steps

Use a small test to place ROMs into the correct system folders, because Onion OS surfaces entries only from expected paths. Create the destination directory if it does not exist, then copy one ROM and reboot or refresh the game list. If the test appears under the system menu and launches, proceed with the rest. The advantage is catching mistakes while only one file is involved. A frequent pitfall is copying to a visually similar but incorrect directory on multi card setups. To reduce that risk, verify the card label and the root path in your file manager before each copy. This quick pause prevents hours of cleanup.

When adding disc based platforms, group files consistently so track files or multiple discs do not fragment your menu. Many users prefer a folder per game containing the cue sheet or a playlist file that references tracks. This approach keeps long filenames readable and avoids double listings. The tradeoff is a deeper directory tree, but it improves organization and makes future metadata fixes easier. If your core supports compressed images like chd, consider converting from cue plus bin to reduce size and simplify file sets. Test one game after conversion, then batch process the rest if results are stable.

For large libraries, copy in batches and verify each group, because scanning thousands of files at once can mask a single bad extension or misplacement. A practical rhythm is ten to twenty titles per pass, followed by a quick menu refresh. Keep a simple log of what you moved and where, which helps isolate errors later. Frequently asked questions

My ROMs do not appear after copying. What should I check first?

Confirm the file is in the correct system folder and uses a supported extension. Then reboot or refresh menus. If still missing, test with a known good ROM to rule out a bad dump and verify you did not copy to the wrong card.

Do I need to extract zip or 7z archives for Onion OS?

It depends on the core. Some read compressed archives while others require extracted files. Test one ROM first. If indexing is slow or the title does not launch, extract that platform’s games consistently to reduce issues.

Artwork is blank even though the game shows up. Why?

Blank art usually means naming does not match your scraper or metadata cache needs a refresh. Verify the title and region tags align with your source and rerun the artwork scan. If only one game fails, rename and retry.

Disc based games have multiple files. How should I organize them?

Keep each game in its own folder with a cue sheet or a playlist file that references the tracks. This avoids duplicates in menus and simplifies swapping discs. Test one title to verify the structure before doing the rest.

After copying, my saves are not writing. What can cause this?

Check that the microSD is not write protected and the filesystem is supported. Create a quick save and see if a file appears in the saves directory. If not, confirm you have the correct path and that the core uses that save type.
