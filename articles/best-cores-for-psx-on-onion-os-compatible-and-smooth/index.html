Best Cores for PSX on Onion OS: Compatible & Smooth

By Jordan Kelly • Published January 4, 2026

Picking the best cores for PSX on Onion OS starts with two constraints that matter most on handhelds, consistent frame pacing and input feel. I prioritize cores that can hold 60 frames with heavy scenes while keeping latency predictable. From there I weigh accuracy features like geometry correction and texture precision only when the device can afford them. The list below reflects that order of operations, with PCSX ReARMed as the baseline and Beetle variants for specific needs. Each item calls out a real setting or scenario where the choice pays off, plus the tradeoff so you can avoid chasing visual upgrades that quietly cost smooth play.

Key takeaways

  • Start with PCSX ReARMed for consistent 60 fps and low latency.
  • Enable Beetle only when geometry or texture accuracy is required.
  • Use per-game overrides to keep global Onion OS settings clean.
  • Turn off scaling filters that add shimmer on PlayStation textures.
  • Verify frame pacing with a quick overlay before finalizing choices.

1) PCSX ReARMed dynarec first

Begin with PCSX ReARMed using dynamic recompiler since it delivers the best speed-to-latency balance on most Onion OS handhelds. In practice, action games that push geometry or transparency, like early 3D racers, tend to remain at a steady refresh when ReARMed uses its default internal resolution and no costly accuracy toggles. A concrete workflow is simple, set ReARMed as the global PSX core, confirm 60 frames in a demanding track, then test two boss arenas. The tradeoff is modest accuracy compared to heavier cores, so texture warping and affine artifacts persist. Accept those if your device struggles to maintain timing, because consistent input response beats visual polish for most libraries and your battery drain remains reasonable under this core.

ReARMed also benefits from conservative audio timing. Keep audio latency modest and avoid stretching that chases sync at the expense of responsiveness. For example, setting a mid-size audio buffer while leaving the internal clock at defaults keeps drum hits in rhythm in music-heavy titles without creating drift that feels gummy. The downside is that a few FMV-heavy scenes can briefly desync sound if your storage is slow. If this shows up, consider preloading save states before a cutscene or trimming background overlays. ReARMed’s limited enhancement feature set is intentional, focus on holding frame time and inputs, and pair it later with per-game overrides when a specific title needs more accuracy.

2) ReARMed with BIOS and safe options

When a few games show glitches or boot quirks, keep PCSX ReARMed but use an authentic BIOS and turn on only safe toggles. A common example is a title that hangs on a logo screen or shows wrong language defaults. Point ReARMed to a verified regional BIOS and avoid enabling expensive hacks. This raises compatibility while preserving the core’s speed. The tradeoff is minimal image improvement, because the BIOS path fixes behavior, not visuals. That is acceptable, since the goal is broad success without leaving the performance envelope. For games that flicker with interlaced fields, use ReARMed’s deinterlace option only if the drop in headroom does not threaten 60 frames. Test it in a busy scene, such as city streets with lots of signage. If frame pacing wobbles, revert and try a shader-based deinterlacer with light cost instead. A smart complement here is controller nuance, like analog deadzone tweaks, which reduce micro-stutter from overcorrection in driving titles. 3) Beetle PSX HW for visual upgrades

Use Beetle PSX HW when your device can sustain its cost and a game benefits from geometry correction or true color precision. As an example, enabling PGXP to reduce affine texture warping in slow-paced adventures can transform camera pans and wall edges while still keeping acceptable input feel. Start with the hardware renderer at native scale, then add one enhancement at a time. The tradeoff is that every toggle eats headroom and battery, and some combinations introduce visual quirks. If a scene with heavy transparency begins to hitch, back off the enhancement that moved you past the threshold. Beetle HW is a scalpel, not a default tool, so reserve it for titles where stability holds and the improvement is obvious in motion rather than just paused screenshots.

Texture filtering needs restraint on PlayStation content. Try a light bilinear setting only if it reduces shimmer without smearing dithering that acts like pseudo transparency. A good test case is a bright menu with diagonal text. If the filter softens legibility, revert and consider a shader from a curated set. Always track input latency after each change, because Beetle HW can feel slightly heavier than ReARMed. If gameplay loses snap, prioritize responsiveness and roll back one enhancement at a time.

4) Beetle PSX software for edge cases

Choose Beetle PSX software renderer when correctness matters more than enhancements and a title misbehaves under other cores. Some effects and timing paths are more consistent under the software renderer, which mirrors the original GPU behavior closely. Use it for problematic transitions or post-processing heavy scenes where hardware renderers show seams. The example to consider is a boss arena with heavy particle effects that flicker under faster cores. Accept the tradeoff, a heavier CPU load that may cap your device at native resolution and cost battery life. If performance drops slightly below target in a few segments, consider short play sessions or mapping a quick toggle to pause before intense scenes to preserve thermals and keep pacing tolerable.

Because this renderer leaves less headroom, keep shaders and scaling conservative. Stick to integer scaling when possible, or the smallest fractional adjustment that fits your screen without uneven sampling. Test known stress points, like dense fog or layered translucency, and track input timing through back-to-back room transitions. If it still dips, swap only that one game to Beetle software using a per-game override, leaving your global core on ReARMed. 5) SwanStation when available

Where supported in your Onion OS build, SwanStation offers a friendly interface and sensible defaults that slot between ReARMed’s speed and Beetle’s accuracy. It often boots a wide range of titles without BIOS quirks and exposes enhancements like texture filtering in a transparent way. A practical example is enabling light geometry correction while keeping native scale to maintain fluid play in third-person adventures. The tradeoff is variability across devices and builds, since not every Onion OS image ships this core. Treat SwanStation as a per-game option rather than your global default, using it when a title needs a little more correctness than ReARMed but does not justify Beetle’s heavier path. If your image lacks the core, stay with ReARMed and test Beetle selectively.

If you adopt SwanStation per game, keep input latency in view. Some enhancement combinations add subtle delay that only shows up during quick parry windows or rhythm sections. Validate by practicing a short combo loop and watching for missed cues. When in doubt, disable the last visual toggle you added and retest. Pair this approach with a quick primer on hotkeys and shortcuts so you can save, retry, and flip settings without breaking flow. A minimal per-game override ensures you do not promote SwanStation globally and accidentally raise your device’s baseline latency for faster genres that benefit more from ReARMed’s feel.

The safest way to mix PSX cores is to use per-game overrides so your global profile stays fast and predictable. The idea is simple, keep PCSX ReARMed as your default, then pin Beetle or SwanStation only on titles that prove they benefit. As a scenario, a 3D platformer shows heavy warping in slow pans. You set Beetle HW with PGXP just for that game, leaving action titles untouched. The tradeoff is added setup time and a small risk of stale configurations, which you solve by documenting changes in a short note and revisiting after firmware updates. Lock decisions with a quick measurement pass using a lightweight overlay. A brief FPS read while moving through a crowded street plus a test of input consistency during a tight timing window reveals whether your chosen core and settings hold up. Keep the overlay minimal to avoid changing behavior. If frame times wobble during effects-heavy scenes, prioritize turning off the last enhancement rather than swapping cores immediately. The tradeoff is that an overlay can add clutter and a tiny cost, so use it for diagnostics only. Frequently asked questions

Which PSX core should I set as the global default on Onion OS?

Set PCSX ReARMed as the global default. It offers strong performance and low latency on most handhelds, then apply per-game overrides only when a title needs features from Beetle or SwanStation.

When is Beetle PSX HW worth the performance cost?

Use Beetle PSX HW when PGXP or precision features visibly improve motion without breaking 60 frames. Test in demanding scenes. If pacing wobbles, roll back the last enhancement.

Do I need a BIOS file for higher compatibility?

Yes, a verified BIOS often resolves boot hangs and regional quirks. Point the core to an authentic regional BIOS and keep other toggles conservative to preserve performance.

How do I avoid global setting conflicts across PSX games?

Use per-game overrides with minimal entries. Specify the desired core and only essential options for that title, leaving your global PSX profile clean and fast.

How can I check if enhancements hurt responsiveness?

Enable a lightweight FPS overlay briefly and run a short input routine in a demanding area. If frame timing or input consistency drops, remove the last change and retest.
