Moonlight on Steam Deck: Sunshine Host Setup Guide

By Jacob Reed • Published February 20, 2026

Moonlight streaming from a Windows PC to a Steam Deck using Sunshine is reliable when you plan for encoder support, network capacity, and input latency. This guide assumes Windows 10 or 11 on the host with a recent NVIDIA, AMD, or Intel GPU that supports hardware encoding. Sunshine provides the host side while Moonlight on the Deck is the client. You will prepare drivers, power profiles, and firewall rules, then select sane defaults for bitrate and codec. We will also test with a quick frame time overlay and step through fixes if stutter or pairing issues appear later.

Key takeaways

  • Confirm hardware encoder support before tuning Moonlight bitrate or codec.
  • Target wired or strong Wi Fi with steady latency under load.
  • Start conservative on bitrate, then increase while monitoring frame time.
  • Use Sunshine service mode and allow required TCP and UDP ports.
  • Validate with a repeatable scene and Moonlight performance overlay.

Plan the work

Define success up front by setting a target resolution, frame rate, and latency envelope that your Steam Deck and network can maintain. A practical baseline is 1080p at 60 frames per second with frame times under 17 milliseconds, stepped down to 720p if Wi Fi conditions vary. Planning forces you to choose between image clarity and smoothness, because bitrate and codec efficiency differ across H.264, HEVC, and AV1. If your Deck is docked and the access point sits nearby, aim higher on bitrate. If you play further from the router, favor steadiness over sharpness and cap frames to reduce packet loss impact.

Identify your host GPU and confirm hardware encoder support, because Sunshine relies on NVENC for NVIDIA, AMF for AMD, and Quick Sync for Intel. A quick check is whether your driver supports HEVC or AV1 encode acceleration, which typically improves quality at the same bitrate compared to H.264. If your GPU lacks HEVC or AV1, do not overreach on bitrate targets, since less efficient compression will saturate Wi Fi sooner. The reason is straightforward: less efficient codecs need more bits for similar detail, raising congestion risk and amplifying stutter during rapid scenes.

Map your network path, noting whether the host uses Ethernet and how the Deck connects. Wired host plus strong Wi Fi 6 or better usually stabilizes jitter, which matters more for input feel than raw throughput. If your router supports Quality of Service, reserve a modest slice for the host ports to reduce contention during downloads. For homes dense with neighboring networks, consider 5 GHz channels with low interference or powerline adapters as a fallback. Planning these routes reduces guesswork later, since most Moonlight problems trace back to inconsistent latency rather than poor CPU or GPU horsepower.

Prepare environment

Stabilize the host first by updating GPU drivers, setting a high performance power plan, and disabling background updaters during play. Driver currency matters because hardware encoders receive fixes that directly affect Sunshine’s reliability and efficiency. On laptops, ensure the dGPU handles encoding by forcing the game and Sunshine to the high performance GPU profile. Limit overlays, capture tools, and RGB apps that hook graphics pipelines, since these can introduce stutter when encoding starts. Finally, confirm Windows Game Mode and hardware accelerated GPU scheduling are enabled, which can slightly reduce render to encode latency under steady loads.

Install Sunshine and configure it to run as a service so streaming launches without logging in. During installation, allow the installer to create firewall rules, or verify them manually if prompts were dismissed. Service mode helps with remote control flows, but be mindful of security by setting a strong PIN and limiting exposed ports to your LAN. If you use third party antivirus, add Sunshine’s binary to an allow list to prevent process injection or network filtering that can break pairing. Before proceeding, reboot once to ensure the driver stack and service state are clean.

Open required ports explicitly if your firewall is strict, and keep rules scoped to private networks to reduce risk. Sunshine typically uses TCP 47984, 47989, and 48010 for control and handshake, plus UDP 47998 through 48010 for the media stream. If your environment uses a third party firewall, adapt the rule syntax in its UI with the same port ranges and directions, verifying rules are limited to the trusted profile.

Execute steps

Start by launching Sunshine on the Windows host, adding your games or desktop capture, and confirming the service runs at boot. On the Steam Deck, install Moonlight from Discover and connect to the same network. Pair to the host by entering the on screen PIN when prompted, then verify the host shows paired status in Sunshine’s web UI. Codec choice should match both GPU capability and network strength. H.264 is most compatible but less efficient, HEVC is a good middle ground on modern GPUs, and AV1 provides better quality per bit when both sides support it. Begin conservative to gauge baseline stability.

Choose an initial bitrate that respects your link budget. A safe starting range for 1080p60 is around 15 to 25 Mbps on Wi Fi, increasing when signal quality is excellent. If you are wired on both ends or right next to the access point, gently push higher bitrates while watching for frame drops. Resolution scaling can offload the network when scenes spike in complexity, so consider 900p or 720p with high quality scaling when bandwidth fluctuates. The key tradeoff is clarity during fast motion versus latency and consistency. Favor stability while you learn your network’s headroom.

Cap the Deck’s frame rate to match the stream when needed, because mismatch can induce perceptual stutter. Vsync or frame pacing controls in Moonlight help align delivered frames with the display refresh. For input latency, enable a low latency mode in Sunshine where available and keep the host’s power state pinned to maximum to avoid clock ramps. Finally, test a cursor movement across uniform backgrounds to detect judder quickly. If the motion looks smooth and input feels immediate, you are ready to iterate settings in small increments to refine image quality further without destabilizing the session.

Validate results

Validation starts with a repeatable test scene, such as a game menu with a moving camera or a timed panning motion over a high contrast texture. Enable Moonlight’s performance overlay to view frame rate, dropped frames, and network throughput. Consistent frame time without spikes is the primary success metric. If you see bursty drops, hold your codec and resolution steady and step the bitrate down by small increments. The aim is finding the knee of the curve where motion remains smooth yet detail is acceptable. Avoid chasing small sharpness gains if they reintroduce micro stutters.

Check input latency by performing a simple click to action test, like firing a weapon on key press and watching for delay. While not a strict measurement, it reveals if the host power management or background tasks are interfering. If input feels mushy, try disabling overlays, verifying hardware accelerated encoding, and moving the host to Ethernet if it was on Wi Fi. You can also reduce the render scale in game to lessen encoder pressure during busy scenes. This balance keeps the stream within your network’s immediate capacity and improves perceived responsiveness.

Compare codecs briefly to see which gives the best quality for your bitrate on your hardware. On many setups, HEVC provides crisper fine detail at equal bitrates relative to H.264, while AV1 can improve further if hardware support exists. However, AV1 encode speed may cap peak frame rates on some GPUs, so monitor both frame rate and quality. Use the following compact table to guide initial choices and tradeoffs. Troubleshoot and optimize

When pairing fails or hosts do not appear, verify both devices share the same subnet and that Sunshine’s TCP ports are open on a private profile. If discovery still fails, add the host by IP in Moonlight to bypass broadcast discovery and confirm reachability. Conflicts from third party firewalls or VPN adapters can hide the service, so temporarily disable them to isolate the cause. Once pairing succeeds, re enable security tools and add targeted allow rules instead of broad exclusions. For stepwise pairing and latency control from a Windows PC to Deck, see the guide on pairing, codecs, and bitrate tuning.

Address stutter by separating causes. If network graphs show spikes, lower bitrate or move closer to the access point. If the host shows steady frames but the stream drops, experiment with a different codec or reduce in game render scale. On laptops, disable panel power saving and set the GPU to maximum performance to prevent clock dips during encoding. For deeper LAN tuning that covers discovery settings and stability tips, review the end to end walkthrough on low latency LAN streaming and apply the parts that match your router features.

Finally, convert stable settings into profiles so you can switch quickly per game. Keep a conservative default with lower bitrate for Wi Fi roaming and a higher quality profile for docked play with Ethernet to the router. Document the working ranges for each codec on your hardware, then iterate only one variable at a time during future tests. This structured approach prevents chasing noise and speeds recovery if a driver update changes behavior. With repeatable profiles, you will spend more time playing and less time retuning whenever you return to Moonlight streaming with Sunshine on the host.

Key terms

Frequently asked questions

Moonlight shows the host but pairing fails. What now?

Confirm Sunshine is running as a service, then restart it. Verify the PIN prompt appears on the host, and check firewall rules for TCP 47984 and 47989. Temporarily disable third party firewalls to isolate blocking, then add precise allow rules.

Streams stutter only during fast motion. How should I tune?

Lower bitrate in small steps, then test a panning scene. If stutter persists, try HEVC or AV1 for better efficiency at the same bitrate. Reduce in game render scale slightly to ease encoder load and stabilize frame delivery.

Which codec should I pick first on older hardware?

Start with H.264 for compatibility. If performance holds and the client supports it, test HEVC at the same bitrate for improved detail. Only try AV1 if both sides support hardware encode and decode reliably.

Do I need Ethernet for good results?

Ethernet on the host improves consistency, but strong Wi Fi 6 can work well. If you cannot wire both ends, keep the host wired and position the Deck near the access point to reduce jitter and maintain steadier frame times.

Why does input feel delayed after a few minutes?

Power saving can downclock the GPU or CPU under light load. Set a high performance power plan, disable panel power saving on laptops, and keep background updaters paused. Verify hardware accelerated encoding remains enabled in Sunshine.
