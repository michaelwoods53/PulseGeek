Change the Default Library Folder in SteamOS

By Brittany Coleman • Published January 5, 2026

Changing the default library folder in SteamOS helps control where installs land and keeps storage balanced. You will work in Desktop Mode and the Steam Settings view, so a mouse and keyboard feel helpful though the trackpads suffice. The goal is to designate a reliable directory on an internal drive, microSD, or external SSD without breaking existing downloads. Expect a brief pause as Steam scans storage and updates the install target. You will hear the faint click of UI confirmations and feel the small latency as the library refreshes, which signals the change took. This guide assumes SteamOS 3.x, a healthy filesystem, and a mounted destination path. If your microSD or external disk is missing, we will address checks before changing anything critical.

Key takeaways

  • Plan the destination path and confirm it persists across reboots.
  • Create the library directory and set owner permissions for steam.
  • Use Steam Settings Storage to add and set the default folder.
  • Verify with an install test and confirm the path receives files.
  • Fix read only errors by checking mounts and filesystem health.

Plan the work

Start by deciding on the destination drive because persistent mounts prevent surprises during updates. A microSD is convenient for large libraries, while an external SSD can bring higher throughput and faster patching. Internal storage offers minimal cabling and stable power but may run tight on space as titles grow. A good rule is to leave at least 15 to 20 percent free on the chosen volume to reduce fragmentation and avoid sudden slowdowns. If the drive will be shared with another device, prefer a file system both can read and write safely. The tradeoff is that cross platform choices like exFAT lack journaling, which can increase risk after abrupt disconnects. Prioritizing stability often means ext4 or btrfs on Deck.

Next, confirm that Desktop Mode can see the target path so Steam can register it cleanly. Open Dolphin and browse to the drive, noting whether it appears under Removable Devices or a custom mount point. This visual check matters because Steam relies on the operating system to present a stable location. If the device requires a passphrase or user action, plan to unlock it before launching Steam. Some users schedule automounting at login to remove extra steps. The tradeoff is that automatic mounts can delay boot if the drive is missing. Planning that behavior now avoids changing defaults later when download queues are active.

Finally, map risks so you keep your games and saves intact during the change. Steam differentiates between library folders and save locations, and Cloud Sync covers many titles, but not all. Backups are a safety net when your destination carries older data or mixed content. A small dry run with a tiny game or a tool like Steam’s shader cache test shows that writes happen in the expected location. Note there is no need to move every title immediately. You can set a new default for fresh installs and migrate a few games after confirming performance. This staged approach reduces the chance of large copy errors.

Prepare environment

Preparation ensures Steam recognizes the path and writes with the right permissions. In Desktop Mode, confirm the drive mounts to a stable location such as /run/media or a user defined directory. If the path moves between reboots, Steam may fall back to internal storage, which leads to confusion. A quick test is to reboot once and verify the same mount point reappears. For microSD, format with a supported file system and label the volume so it is easy to spot in the Storage UI. If you use btrfs or ext4 you get journaling or copy on write benefits, while exFAT trades features for broader device compatibility. Choose based on your portability needs.

Create a dedicated directory for the library so permission scopes stay minimal and predictable. Using a subfolder under the mounted volume like Games or SteamLibrary keeps content separate from other files. Ownership must align with the steam user session so downloads can create directories and write manifests cleanly. If you see read only or permission denied, it usually means the mount options or ownership mismatch. A conservative approach is to set the directory owner to your normal Desktop Mode user and let Steam manage within. The tradeoff is looser separation on shared systems, which is usually acceptable on a personal Deck.

If the drive is formatted with a permissionless file system like exFAT, ownership commands will not persist and you should rely on mount options instead. Watch for command output and the feel of the keyboard pause as the shell completes the mkdir and chown operations.

Execute steps

With the folder ready, shift to Steam’s Storage view to register it and set the default destination. Launch Steam in Desktop Mode and open Settings then Storage. Steam enumerates volumes and shows available space by device. If the new folder is not visible, use Add Drive under the target device to pick your prepared directory. The UI will verify writability and reflect the added path in the list. You may notice a brief pause as it scans for existing library metadata. This is normal and introduces a short ripple as the window updates. The tradeoff of using the UI is less scriptable control, but it reduces risk of typos and invalid paths.

After adding the folder, designate it as the default so new downloads land there automatically. In the Storage list, select the new path and choose the context action to make it default. Steam marks the choice, and you will see a subtle highlight around the entry. Older installs stay where they are until you move them individually. This separation avoids long copies during busy windows and lets you test performance. If you plan on migrating many games later, note which titles have large shader caches that can lengthen move time. A quiet drive with steady LED blinks indicates a healthy transfer when you do move content.

If any option is missing, it likely means the mount is not writable or Steam has not refreshed its device list. Close and relaunch Steam before reconfiguring the path to avoid partial state. Keeping the sequence tight will help you finish the change without unnecessary retries or guesswork.

Validate results

Validation proves the new default library folder actually receives files. Pick a small free tool or lightweight game and click Install while watching the destination label in the dialog. The path shown should match your configured directory, including the device name. Listen for the drive’s soft activity and watch LEDs if available, which confirm writes. In Dolphin, you should see a steamapps directory appear with appmanifest files. If this structure does not show, the default may not be set or Steam might lack permission. Cancel the download before it grows and return to Storage to recheck the default marker.

Next, confirm persistence by restarting Steam and repeating the install prompt check. Some setups mount external drives after user login, and Steam might load before mounts are ready. If the folder is missing at startup, the default can revert silently to internal storage. You can mitigate this by launching Steam after the device mounts or by enabling automount with a delay. The tradeoff is a slightly slower login to guarantee the path. Watching for the brief lag as the Storage panel refreshes after relaunch acts as a cue that Steam rescanned devices.

Finally, validate performance and path stability under load. Start a moderate download while browsing the Steam library to see if UI remains responsive. Stuttering can indicate a slow card or a cable issue on an external SSD. Dolphin’s Properties view provides a quick check of remaining space and file growth. If the download completes but the game fails to launch, verify execute permissions for Proton files are intact and that no antivirus from a shared partition interferes. Keeping logs minimal and focusing on a consistent experience during one or two test installs is enough to trust the setup for future titles.

Troubleshoot and optimize

When Steam reports read only, the mount usually lacks write flags or the file system enforces constraints. Check the device’s mount options and confirm you did not fall back to a transient path like a loop mount. For microSD cards, test in Desktop Mode and try a different reader if writes seem sluggish. If repair is needed, schedule checks when the device is unmounted to avoid data loss. Keeping simple ownership and avoiding deeply nested permissions reduces surprises. If you suspect file system errors, use platform tools to perform a non destructive scan before trying again. You will hear smoother activity once the device stops retrying writes.

If the new library folder disappears after reboot, the drive is not mounting early enough. Add a reliable automount or unlock step before launching Steam. KDE’s settings can automount removable devices at login, which balances convenience and safety. The tradeoff is a short delay while volumes mount. For external SSDs, try a different USB port to improve power stability. If Dolphin shows the device but Steam does not, relaunch Steam so it refreshes devices. This refresh is often the missing step when troubleshooting. Threads of activity resuming in the UI indicate the scan occurred.

When deciding between making this path permanent or keeping it optional, weigh portability against resilience. ext4 or btrfs on the Deck deliver journaling or snapshot friendly behavior, which is helpful when moving many games. Cross device formats like exFAT allow sharing with consoles or PCs at the cost of metadata fidelity. For a balanced approach, keep the default on a robust file system and occasionally move titles elsewhere for travel. Frequently asked questions

Do I need to move existing games when I change the default?

No. Existing games stay where they are until you move them. The default affects only new installs. You can migrate titles later from the Storage view with the Move option.

Why does Steam revert to internal storage after reboot?

The external drive likely mounted late or not at all. Ensure it automounts before Steam launches or start Steam after mounts complete to preserve the default path.

How do I fix a read only error on my library folder?

Check mount options and file system health. Ensure the directory is writable by your user and the device uses a mode that allows writes for your chosen format.

Is exFAT safe to use for the Steam library?

exFAT works for portability but lacks journaling. It is more sensitive to improper disconnects. If stability is the priority, prefer ext4 or btrfs on the Deck.

Can I keep multiple library folders and switch between them?

Yes. Add multiple folders in Storage. Set one as default for new installs and switch as needed. Steam will list installed games from all registered paths.
