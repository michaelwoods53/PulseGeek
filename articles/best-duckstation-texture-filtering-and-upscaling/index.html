Best DuckStation Texture Filtering and Upscaling

By Joshua Bennett • Published February 2, 2026

Picking the best DuckStation texture filtering and upscaling settings is about matching the game’s art with your display and GPU budget. We focus on upscaling the internal resolution first, then applying texture filtering that suits 2D or 3D content so edges look intentional rather than smeared. Each item explains when a choice helps, a concrete scenario that shows the impact, and a tradeoff to watch for. You will leave with a repeatable approach for per game tuning and a short checklist to verify results without guesswork.

Key takeaways

  • Raise internal resolution before applying any texture filtering or shaders.
  • Use nearest for pixel art and bilinear for textured 3D scenes.
  • Enable anisotropic filtering to stabilize slanted floor and wall textures.
  • Prefer integer scaling to avoid shimmer and ringing on UI elements.
  • Create per game overrides when global filtering blurs menus or fonts.

1) Set internal resolution first

Prioritize internal resolution scaling because it multiplies polygon and texture sampling before any filter touches the image. For example, raising internal resolution to 3x or 4x on a 1080p display can remove staircase edges on 3D models while keeping texture details legible without heavy smoothing. This works because more samples reduce aliasing at the source, which makes later filtering gentle rather than corrective. The tradeoff is GPU cost and potential VRAM pressure on integrated graphics. If you push the multiplier too far, frame pacing can wobble and shader compilation hitches appear. A practical rule is to scale until GPU usage sits below your monitor’s refresh budget while testing a demanding scene, then only add light filtering if the result still shows shimmer on angled surfaces.

Section highlights

  • Boost internal resolution before applying any additional texture smoothing.
  • Stop scaling when GPU headroom stays safe during busy scenes.

2) Choose nearest for 2D pixel art

Use nearest neighbor filtering for sprite heavy 2D games to preserve sharp edges and deliberate pixel patterns. In a platformer with chunky fonts and outlined characters, nearest maintains the artist’s grid while internal resolution scaling reduces jaggies on diagonals. This combination keeps HUD text readable and prevents color bleeding across sprite borders. The downside is visible stair steps on diagonals if the internal resolution multiplier is too low or if non integer scaling stretches the image. To mitigate, pair nearest with integer scaling and nudge internal resolution upward until edges stop crawling during scrolling. Avoid adding smoothing shaders here because they can wash out dithered shading and make fine UI elements look soft. If a menu still shows flicker, raise resolution one notch rather than swapping filters.

Section highlights

  • Use nearest plus integer scaling for sharp sprites and HUD text.
  • Increase internal resolution to reduce diagonal crawl without blur.

3) Use bilinear for textured 3D scenes

Bilinear filtering suits 3D scenes where low resolution textures stretch across polygonal surfaces, softening seams without destroying detail. Picture a racing game with track banners and asphalt patterns that shimmer at distance. After raising internal resolution, a bilinear pass reduces pixel crawl on the road while keeping signage readable. The tradeoff is mild blur on UI overlays or fine text, especially when the game mixes 3D backdrops with 2D interface elements. If menus blur, restrict bilinear via per game overrides or explore backend options that better match your GPU. Section highlights

  • Bilinear calms shimmer on stretched textures in 3D environments.
  • Use per game overrides if menus or fonts become noticeably soft.

4) Limit filtering to protect UI sharpness

Scope filtering so it benefits 3D surfaces but spares UI layers that demand crisp edges. In games that render 2D fonts over 3D scenes, broad smoothing can blur menu text and item icons. A practical pattern is to set a mild filter globally, then create exceptions for titles that mix rendering styles aggressively. If your backend offers toggles that separate 2D surfaces or allows post processing only on certain passes, test that path first. The tradeoff is added configuration and the chance some titles do not expose separate layers cleanly. Section highlights

  • Apply selective filtering so 2D UI layers remain sharp and readable.
  • Create exceptions for mixed 2D and 3D titles that blur text.

5) Enable anisotropic filtering for angles

Anisotropic filtering stabilizes textures viewed at oblique angles by increasing detail sampling along the axis of distortion. On dungeon floors, road surfaces, or wall murals, it tames shimmering and preserves patterns as they recede into the distance. Start at 8x and test a busy hallway scene, then raise to 16x only if you still notice crawling lines during camera pans. The tradeoff is minor GPU overhead that can matter on integrated graphics or when paired with high internal resolution. If performance dips, drop anisotropic one step before reducing resolution, because it usually improves clarity where bilinear alone cannot. Watch for diminishing returns on titles with ultra low resolution textures where extra samples cannot reconstruct detail that simply is not there.

Section highlights

  • Anisotropic filtering cuts shimmer on floors and walls viewed at angles.
  • Prefer lowering AF one notch before dropping internal resolution.

6) Handle dithering with care

PS1 era titles often rely on dithering to simulate more colors. Upscaling and filtering can exaggerate these patterns or blur them into muddy gradients. If your emulator exposes a dither removal or true color presentation toggle, test it after raising internal resolution to see whether gradients smooth out without banding. In a foggy scene, removing dither may produce cleaner skies, but it risks altering the game’s intended look and can introduce flat shading. The tradeoff is aesthetic authenticity versus cleanliness. When unsure, keep dithering enabled and rely on resolution scaling plus light bilinear filtering instead. If removing dither triggers instability with your chosen backend, consult a broad troubleshooting checklist that covers GPU behavior and platform quirks with reproducible steps for driver related issues.

Section highlights

  • Test dither removal only after scaling resolution to reduce artifacts.
  • Favor authenticity when unsure, because removal can flatten shading.

7) Prefer integer scaling to avoid shimmer

Integer scaling multiplies the source image by whole numbers to avoid fractional sampling, which can cause shimmer, ringing, or soft edges. For 240p style content, 4x to 5x on 1080p or 1440p panels often lands near a clean fit. In a menu or inventory screen with fine borders, integer scaling keeps line weights consistent and prevents gray halos around text. The tradeoff is black bars or partial frame usage when the result does not perfectly fill your display. If that bothers you, experiment with slight overscan or a subtle upscale in your GPU control panel, but stop if you see crawling edges during scroll tests. Pair integer scaling with nearest neighbor on 2D games and with light bilinear on 3D titles to balance sharpness and stability.

Section highlights

  • Use whole number scaling to prevent shimmer and ringing artifacts.
  • Accept small borders if necessary to keep pixels aligned cleanly.

8) Upscale through resolution, not heavy smoothing

Resist the urge to stack multiple smoothing passes, because they can erase texture features that define a game’s mood. A cleaner path is internal resolution first, then exactly one light filter where needed. In a survival horror title with grainy walls, over smoothing can remove the intentional grit that cues atmosphere and depth. By contrast, a 3x or 4x resolution increase preserves the feel while reducing harsh edges. The tradeoff is that some micro shimmer may persist on steep angles, which is where anisotropic filtering earns its keep. If you try an advanced shader, compare freeze frames and motion, and roll back when fine details disappear. For crash prone shader experiments, a fast backend swap guide can help you recover stability quickly and resume testing without data loss.

Section highlights

  • Favor resolution scaling plus one mild filter to preserve texture detail.
  • Back out of shaders that erase intended grit or surface cues.

9) Balance PGXP with filtering

PGXP corrects vertex precision and reduces wobble on PS1 geometry, which can change how textures map to surfaces. After enabling PGXP, reassess filtering because crisper geometry often needs less smoothing to look stable. For example, a castle wall that previously shimmered might settle enough that bilinear can be dialed back or anisotropic lowered one notch. The tradeoff is that some games rely on quirks PGXP alters, leading to texture seams or visual oddities. If you encounter odd mapping or breakage, revert the most aggressive PGXP options first, then reapply your filtering baseline. For methodical tuning of geometry features, consult advice on reducing wobble and warping with safe settings that explain typical edge cases.

Section highlights

  • Recheck filters after enabling PGXP since geometry stability changes needs.
  • Back off aggressive PGXP options if texture seams appear.

10) Create per game overrides

Per game profiles are the safest way to keep global defaults tidy while handling outliers. Start with a baseline of internal resolution, a preferred filter, anisotropic level, and integer scaling. When a title shows blurry menus or shimmering floors, create a game specific override that tweaks one setting at a time. In a role playing game with tiny fonts, force nearest for menus while leaving bilinear for 3D scenes. The tradeoff is management overhead, so document what changed and why in a note or simple filename hint. If an override crashes during boot or switching backends, rely on a troubleshooting path that covers GPU induced startup problems and cache resets to restore a known good baseline.

  • Use per game profiles to isolate fixes without polluting global defaults.
  • Change one setting at a time and record the rationale.

Frequently asked questions

Should I raise internal resolution or enable filtering first?

Raise internal resolution first, then add minimal filtering only if needed. Scaling reduces aliasing at the source and usually lessens how much smoothing you need later.

What filtering should I use for 2D games?

Use nearest with integer scaling. This keeps pixels aligned and text crisp while avoiding blur from smoothing filters.

Is anisotropic filtering worth enabling on low end GPUs?

Usually yes at moderate levels like 8x. It improves clarity on angled textures with a small performance cost compared to raising internal resolution.

Why do menus look blurry after I enable bilinear?

Bilinear softens edges on all textured elements. Create a per game override or reduce filtering so UI layers stay crisp while 3D surfaces remain stable.

Do I need different settings for every game?

Keep a solid global baseline and adjust only when a title shows issues. Per game overrides help you fix edge cases without changing defaults.
