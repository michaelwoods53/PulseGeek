Frequently asked questions

Is Vulkan always faster than OpenGL in DuckStation?

No. Vulkan often reduces CPU overhead, but some drivers or games run smoother on OpenGL. Test both backends in the same scene and compare frametime stability and input latency before deciding.

Why do I get a Vulkan device lost error?

This typically indicates the driver reset the GPU or a pipeline fault occurred. Reproduce the issue, try backend switching, review recent driver changes, and test without overlays to isolate the cause.

Should I use threaded presentation with VSync?

Try it. Threaded presentation can smooth delivery on some drivers, but may add latency or instability on others. Enable it and watch frametime graphs. Keep the setting only if stutter decreases consistently.

What internal resolution is safe for low end GPUs?

Start near native. Increase stepwise while monitoring frametime variance. If spikes appear or clocks throttle, return to the last stable level and adjust filtering instead of resolution.

When should I use the software renderer?

Use it briefly to confirm whether artifacts come from hardware pipelines. It is slower but more accurate. If glitches disappear under software rendering, focus on backend and driver options.
