Find a Game’s AppID for Proton Overrides on Deck

By Andrew Miller • Published February 22, 2026

Finding the right AppID is the small hinge that swings the big door of Proton overrides on Steam Deck. With a precise identifier, you can scope changes to a single game without affecting others or global settings. This guide explains multiple paths to the AppID, from reading Steam manifests to scanning compatdata, then shows how to verify the result before applying overrides. We assume SteamOS on a Deck, a basic comfort with file paths, and either Desktop Mode or a terminal. You will see why AppID accuracy prevents broken prefixes, which can waste time and lead to confusing behavior, and how each method balances speed, confidence, and repeatability.

Key takeaways

  • AppID determines exactly which game receives your Proton override.
  • Manifests and compatdata directories provide fast, local AppID lookups.
  • Cross check by matching install folder, prefix size, and last run time.
  • Prefer grep on manifests for accuracy without launching the game.

Plan the work

Start by mapping your available methods because the fastest route depends on what access you have and whether the game is installed. If the title is already on the Deck, the AppID appears in local data like compatdata folders or appmanifest files. For an uninstalled game, a quick check of the store page reveals the identifier in the URL, though you may prefer local-only approaches when offline. A realistic rule is pick two methods and compare results for certainty. For example, use an appmanifest search in Desktop Mode, then confirm by checking compatdata size after a short launch. This double-check avoids overrides hitting the wrong title, which can create misleading behavior.

Clarify what you will do with the AppID because that informs which lookup is safer. Per-game Proton overrides rely on the identifier to target the correct prefix directory under steamapps/compatdata, which holds Wine configuration and game files created by Proton. If you plan to adjust advanced options like PROTON_LOG or custom launch flags, a mistake can create logs for the wrong game and obscure the root cause. When choosing a lookup path, favor one that does not require launching the game if it is unstable. Reading a manifest avoids crashes during startup while still returning the precise number you need for overrides.

Decide when to consult a broader compatibility perspective so you do not over-index on the AppID step. While you can proceed directly to overrides, context on Proton versions and settings often prevents unnecessary fiddling. Prepare environment

Switch to Desktop Mode because file visibility and search speed improve dramatically outside Gaming Mode. Open Dolphin, the file manager, and enable showing hidden files so you can reach ~/.local/share/Steam. This directory contains appmanifest files and the compatdata folder used by Proton. If you prefer the terminal, open Konsole and confirm that the grep and sed utilities are present, which they are on SteamOS by default. The goal is to be ready for a quick manifest search or a directory listing without needing extra packages. If another user account installed the game, note that manifests will live under that user’s home, which changes the path you must traverse during the search.

Ensure the target game is fully installed if you plan to read manifests, because appmanifest files are created during installation and updated when content changes. If the game is not installed, you can still find the AppID through the store page URL from Desktop Mode’s browser. Keep in mind that Proton’s compatdata folder is created only after a first launch, so folder-based lookups do not apply before any run. As a safeguard, capture a quick backup of any custom Proton options before you begin, in case you uncover a mis-targeted override that should be removed or adjusted after the lookup is complete.

Collect context to help validate the AppID later, such as the exact install folder name under steamapps/common, approximate size on disk, and the expected last played time. These cues let you match the right compatdata folder if multiple AppIDs exist for similar titles like editions or remasters. A simple heuristic is that the largest prefix directory updated at the time you launched the game is usually the correct one. Edge cases include games that spawn auxiliary processes with separate AppIDs for launchers. In these cases, manifests remain the safest primary source for the identifier because they map title names directly to numeric IDs.

Execute steps

Use a manifest search for a precise and offline-friendly AppID lookup. Appmanifest files live in ~/.local/share/Steam/steamapps and follow the pattern appmanifest_XXXXXX.acf. Each contains the AppID and game name, so searching by the title string is fast and accurate. The outcome you want is a single numeric identifier you can use for Proton overrides and per-game compatibility tools. If your library contains many similar names, search by a distinctive word from the title to avoid false positives. As a limitation, this method only works for installed games. If the search returns multiple manifests, validate by checking the corresponding steamapps/common folder and size on disk for a consistent match.

Check the compatdata directory if the game has been launched at least once because Proton creates a prefix at steamapps/compatdata/APPID. List that directory and sort by modification time to find the most recent folder after launching the target game for a minute. This approach is useful when manifests are ambiguous or when a launcher complicates name-based searches. A known limitation is multi-process titles where the launcher and the game use different IDs. In that case, the largest prefix updated most recently usually corresponds to the game, while a smaller or older prefix maps to the launcher. Verify against the install folder name to reinforce confidence before applying any override.

Record your AppID and proceed to the per-game override flow so changes affect only that title. In Gaming Mode, open the game’s Properties, Compatibility, and enable a specific Proton version. Alternatively, in Desktop Mode you can add launch options or environment variables that Proton reads per title. Validate results

Cross check the AppID against the installed folder because the wrong identifier sends changes to the wrong place. Find the game directory under steamapps/common and confirm its presence aligns with your manifest and the name you searched. An extra validation step is to compare the size on disk you see in Properties with the footprint of the compatdata prefix. If the game is small yet the prefix is enormous, you may be looking at a launcher’s ID rather than the game’s. The goal is converging evidence from two or three cues that point to a single AppID so you minimize the risk of misapplied overrides and avoid chasing misleading test results.

Run a quick log test to ensure the override attaches to the expected prefix. Add a temporary launch option like PROTON_LOG=1 %command% and start the game, then inspect steam-APPID.log in your home directory or the Steam logs folder. The filename should include the AppID you recorded. If the log file uses a different number, your override targeted another title or a launcher process. Remove the temporary flag once you confirm the mapping, since verbose logs can add overhead. This test is simple yet powerful because it reveals exactly where Proton is routing its workload and whether your configuration is attached to the right AppID.

Stage overrides incrementally so you can attribute effects cleanly and roll back safely. Start with a single change like choosing Proton Experimental or a known good GE build before adding flags. After each adjustment, launch and observe one or two reproducible behaviors such as opening cutscenes or loading screens. If something improves, document the AppID, the Proton version, and the specific flag used. If nothing changes, revert and try the next option. This measured approach prevents configuration drift, where many changes pile up and interactions obscure which element helped. It also shortens troubleshooting if you later revisit the setup after an update.

Troubleshoot and optimize

If the manifest search returns multiple candidates, reduce ambiguity by filtering names and then correlating with timestamps. Use more of the unique title string or edition marker and re-run the search. Next, identify which appmanifest was updated most recently and compare that timing to your last install or update. When editions share assets, both manifests can exist, but only one matches the game you launched. A careful check of the corresponding compatdata/APPID directory’s modification time adds a second confirming signal. If all signals conflict, uninstalling and reinstalling the specific edition can regenerate a single manifest, simplifying the lookup before you proceed with overrides.

When a launcher spawns the actual game process, you might collect the launcher’s AppID instead of the game’s. To resolve this, briefly launch and then inspect both recently updated compatdata folders. The game’s prefix is typically larger and continues changing longer than the launcher’s. If in doubt, scan logs for executable names that match the game rather than the launcher. You can also capture a short run with the log flag to reveal which prefix is actively used during gameplay. Accept that some titles require this two-step identification, and prefer the manifest as the tie breaker because it maps the final game name more reliably.

Frequently asked questions

The manifest shows multiple AppIDs for similar editions. Which one?

Filter by a unique word in the edition name, then verify the corresponding compatdata folder changed after your last launch. Prefer the prefix with larger size and recent timestamps that match your test run.

Do non Steam games have an AppID I can use?

Non Steam shortcuts receive pseudo identifiers generated by Steam, but they do not match public AppIDs. Use the shortcut specific ID shown in Steam’s configuration when applying per game options to those entries.

The override applied but nothing changed. Is the AppID wrong?

Confirm with a temporary PROTON_LOG flag and check the log filename for your expected number. If it differs, you targeted the wrong title. If it matches, the issue likely requires a different Proton version or setting.

Can I find an AppID without installing the game?

Yes. The store page URL contains the numeric identifier in plain view. This is useful when you cannot install yet, though local methods are better for confirming the specific edition you plan to run.
