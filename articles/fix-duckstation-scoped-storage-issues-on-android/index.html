Fix DuckStation Scoped Storage Issues on Android

By Joshua Bennett • Published March 6, 2026

Scoped storage on Android changes how apps like DuckStation see files, which often confuses BIOS selection and game scanning. This guide targets practical fixes that align with Android security while preserving a clean library. You will grant access correctly, choose stable directories with the Storage Access Framework, and confirm everything with quick validation checks. I assume a recent Android version, basic familiarity with file managers, and optional adb access. If you only use your phone, follow the manual steps. If you tinker with a PC, the adb checks help confirm what the UI shows.

Key takeaways

  • Use Storage Access Framework to select stable game and BIOS directories.
  • Pick internal app-owned or Documents subfolders to avoid permission loss.
  • Grant media permissions on Android 13 plus for artwork and dumps.
  • Validate with repeatable scans and save writes after each change.
  • Avoid moving or renaming folders once DuckStation has tree access.

Quick start checklist

  1. Open app info: confirm Files and media access is allowed.
  2. Choose stable folders: pick BIOS and games using the system picker.
  3. Rescan library: run a scan and confirm counts match expectations.
  4. Write a test save: create or overwrite a save to verify writes.
  5. Keep paths steady: avoid moving directories after granting access.

Plan the work

Start by naming the exact symptom, because storage failures look similar yet require different actions. If DuckStation cannot see your BIOS after choosing a folder, the problem is usually a bad directory choice or missing Storage Access Framework permission. If games show during a scan but disappear later, the likely cause is moving or renaming the granted folder. Write errors on saves or save states often point to read-only locations or outdated cached paths. Labeling the symptom first narrows the playbook and avoids disruptive resets. A practical rule is to change one variable at a time, then retest in a minute or less. That pace keeps troubleshooting focused and prevents you from stacking unrelated fixes that mask the real issue.

Define your storage targets early, because scoped storage grants are directory based and persistent. Decide where the BIOS will live and where your games will stay, then stick to those choices. Internal storage paths under Documents or the app’s private directory tend to remain stable through updates. External SD cards work when formatted as portable storage, but they can remount with different identifiers, which breaks a remembered grant. If you rely on removable media, plan to reauthorize the top folder after any card changes. Stability beats flexibility for emulation setups. The goal is predictable access that minimizes rescans and keeps saves consistent across reboots.

Choose the lowest directory that still makes sense, because granting a high-level tree increases risk and complexity. Giving access to an entire root like Download invites clutter and future conflicts with unrelated files. Pick a dedicated games folder and a separate BIOS folder that you will not rename. That separation simplifies future checks and makes it clearer which grant failed if one path breaks. It also keeps your scans fast, since DuckStation does not waste time traversing archives or screenshots. When you keep boundaries tight, your troubleshooting steps stay surgical and your device remains tidy. Structure now saves time later when testing or migrating devices.

Prepare environment

Select folders using Android’s system picker, because scoped storage relies on the Storage Access Framework to record durable permissions. Inside DuckStation, choose Add Game Directory and Add BIOS Directory, then navigate with the picker to a dedicated subfolder you plan to keep unchanged. Favor internal storage under Documents or a clearly named folder at the top level. Avoid Downloads or transient cache locations, which often get cleaned or reorganized. If you use an SD card, confirm it is mounted and accessible before granting access. Remind yourself that the app receives a tree URI, not a raw file path, so later moves or renames outside the picker can break the grant without any error until you rescan.

On Android 13 and newer, media permissions are split by type, which can affect artwork import or dumps. Ensure Images, Audio, and Video permissions are allowed if DuckStation uses media pickers or caches cover art. The toggle names vary by vendor, but the presence of separate categories is consistent across stock Android. If the app cannot read artwork even though game scanning works, the issue might be the media scope rather than the directory grant. On earlier Android versions, a single Files and media toggle controls access. Revisit App info whenever symptoms appear after a system update, because permission migrations sometimes reset toggles silently.

Use a quick comparison to choose reliable locations, since path stability is the top goal. Internal storage typically survives reboots and updates with consistent identifiers, while SD cards can remount differently. Cloud-synced folders may rename or move files during sync, which invalidates grants. A small decision matrix helps. Keep BIOS in a fixed internal folder and store games in a nearby sibling directory to simplify backups. If you must use an SD card, grant access to the card’s games folder directly and avoid nested grants within volatile app directories. When migration time arrives, reauthorize both top-level folders through the system picker before copying files.

Execute steps

Follow a stable order so each change is easy to undo if it misses. Begin with permissions, because the absence of access blocks every other test and muddies results. Next verify that BIOS and game directories are granted via the system picker, not a file manager shortcut. Then rescan and watch for consistent counts and timestamps. If scans differ each run, the directory is unstable or not truly under the granted tree. Only after those pass should you test write paths with a save state. That final check confirms both read and write scopes. If you must reset, clear only DuckStation’s storage and grants, not global media indexes, to avoid side effects.

When a UI leaves doubt, confirm with adb so you can read what Android recorded. Without naming a specific package, you can still verify permission states and the presence of persisted tree URIs. The goal is to compare what DuckStation shows with what the system knows. Expect to see granted runtime permissions for media categories on Android 13 and a record of directory access persisted across reboots. If those are missing, your earlier UI steps did not complete or the vendor skin altered toggles. Use the checks below to stay objective before you reattempt folder selection inside the app.

If you use DuckStation on multiple devices, align folder strategies so grants behave the same way. Keep BIOS and games in parallel directories and avoid mixing SD and internal paths across phones. That consistency helps when comparing behavior with friends or moving between devices. Validate results

Validation requires repeatability, so run the same scan twice and compare counts. If results diverge, the granted directory is unstable or includes items that change during indexing. Remove archives or mixed file types that can confuse filters and rescan. Check the scan timestamp and game list ordering, then reboot the phone and open the app to confirm persistence. A successful run shows identical counts before and after reboot. That pattern demonstrates durable access and rules out transient media index issues. If artwork is missing while games appear, recheck media permissions rather than the folder grant, because those are separate scopes in modern Android.

Next verify BIOS access by loading a title that requires it and watching for silent fallbacks. Some emulators warn loudly, while others continue with degraded features when BIOS is not readable. Confirm the BIOS path inside settings points to the same granted folder chosen via the picker. If the path string looks like a Document URI rather than a raw path, that is expected under scoped storage. A test run that shows consistent behavior across two titles is a good proxy for stability. Should the app prompt again for BIOS selection, the original grant likely referenced a moved folder or lost permission on reboot.

Finally, test writes by creating a small save and then inspecting its presence using the emulator’s save manager. If visible, close the app from the switcher to force a cold start, then check again. A stable setup keeps the save file and its timestamp intact. If writes fail only on SD card but succeed on internal storage, you have confirmed a remount or permission edge case. Moving the games folder to internal storage and reauthorizing often resolves that discrepancy. Troubleshoot and optimize

If scans still fail, reset only storage-related state to avoid collateral changes. Clear DuckStation’s storage and cache in App info, then reopen and reauthorize folders with the system picker. Avoid third-party file managers during authorization, because some bypass the framework and create temporary links that vanish after reboots. If the picker does not show your SD card, ensure it is mounted and readable in system settings before trying again. For stubborn missing files, copy one test game into the granted folder and rescan. That isolates whether the grant works independently from the rest of your library layout or filename patterns.

When permission toggles look correct but behavior differs, suspect vendor customizations. Some OEMs bundle cleaners that move or compress files automatically, which invalidates tree access silently. Disable aggressive battery or storage cleaners for the emulator and for your games folder, then retest. If the SD card unmounts during heavy use, migrate games to internal storage and compare stability over the next day. This A or B experiment helps choose a permanent home. If internal is clearly more reliable, keep the SD card for backups and artwork only, which reduces churn in the granted tree.

After everything is stable, add small quality-of-life improvements that respect scoped storage limits. Keep short directory names without spaces to simplify visual checks in the picker. Maintain a separate artwork folder and reauthorize it if needed, so media permissions remain tidy on Android 13. Document your BIOS and games locations in a note, then avoid further changes. Frequently asked questions

Why do my games disappear after a reboot even after I added the folder?

The grant likely targeted a folder that was moved, renamed, or on an SD card that remounted differently. Reauthorize the exact top folder using the system picker and avoid subsequent renames.

Can I grant access to the entire storage to avoid repeated prompts?

Granting very broad roots increases risk and may still fail after reorganizations. Pick minimal, stable directories for BIOS and games using the picker to keep access durable and scans fast.

Do I need different permissions on Android 13 for artwork to load?

Yes. Android 13 splits media permissions by type. Allow Images, Audio, and Video as needed in App info if artwork or dumps are not readable while game scans work.

Should I store BIOS and games on an SD card or internal storage?

Internal storage is typically more stable. SD cards can remount with different identifiers which breaks persisted access. If you use a card, grant the card folder directly and keep names unchanged.

Will clearing app data fix storage problems without side effects?

Clearing DuckStation storage removes grants and cached paths which can resolve bad states. You will need to reselect BIOS and game directories with the system picker and rescan your library.
