Overwatch 2 on Deck: Ricochet Support and Status

By Ryan Turner • Published January 27, 2026

Players want a straight answer on Overwatch 2 and Ricochet across Steam Deck configurations. This piece explains what Ricochet expects from the operating system, how SteamOS differs from Windows, and when that gap blocks online play. The goal is to help you choose a path that fits your time and risk tolerance without chasing unproven tweaks.

Key takeaways

  • Ricochet relies on Windows kernel access, which SteamOS cannot provide.
  • Windows on Deck can satisfy Ricochet, but performance and upkeep vary.

  • Decide by intent: ranked sessions favor Windows, casual favors alternatives.
  • Recheck status after major OS, driver, or anti-cheat updates.

Concepts and definitions

Ricochet is an anti-cheat system that includes a kernel-mode driver on Windows, and that requirement shapes Overwatch 2 support on Deck. Kernel-mode means the software expects privileged access to the operating system to monitor for tampering in real time. SteamOS is Linux-based and runs Windows games through Proton, which translates calls for compatibility but does not expose a Windows kernel. That architectural gap blocks kernel drivers by design. While Proton successfully supports many user-mode anti-cheat systems, kernel-mode tools typically cannot initialize. This is not a judgment about security strength; it is a platform mismatch. The practical takeaway is simple: on SteamOS, Overwatch 2’s Ricochet component will not load natively, so online modes dependent on it are inaccessible.

Dual-booting or replacing SteamOS with Windows changes the equation because Ricochet’s driver can run on a supported Windows build. That option introduces a different class of tradeoffs: storage partitioning, driver setup, and ongoing updates. Players should consider a rule of thumb for portable sessions. If you need consistent online matchmaking, Windows aligns better with Ricochet’s expectations. If you prefer maintenance-light gaming and are willing to play titles with Linux-friendly anti-cheat, stay on SteamOS. The Steam Deck can run Windows, but it becomes a small PC that needs driver care. Battery life and suspend behavior can also shift under Windows compared with SteamOS, which matters for travel or couch use.

Status pages and compatibility trackers help set expectations, but they cannot override kernel reality. Linux cannot load Windows kernel drivers safely, and anti-cheat vendors rarely ship separate Linux drivers for consumer gaming. When you see advice suggesting toggles or obscure Proton flags to bypass the driver requirement, treat it as high-risk. At best, such tweaks fail; at worst, they breach terms that protect competitive integrity. Frequently asked questions

Can Overwatch 2 run on SteamOS with Ricochet?

No. Ricochet includes a Windows kernel driver that SteamOS cannot load. Proton does not provide kernel-level access, so online modes that rely on Ricochet will not function on SteamOS.

Does installing Windows on Steam Deck enable online play?

Installing Windows can satisfy Ricochet's driver requirements, which enables online modes. Expect tradeoffs such as setup time, driver maintenance, different battery behavior, and occasional suspend limitations compared with SteamOS.

Is there a safe workaround to bypass Ricochet on Linux?

No safe workaround exists. Attempts to spoof or bypass kernel drivers risk enforcement action and can compromise system integrity. Use Windows, remote play, or alternative games that support Linux-friendly anti-cheat.

Will Proton eventually support Ricochet?

Support would require vendor cooperation or a different anti-cheat model. Monitor official announcements and major Proton or OS milestones, but do not assume near-term change without clear statements from stakeholders.

Is remote play a good option for Overwatch 2 on Deck?

Remote play can work if you tolerate some latency and have strong network conditions. It avoids Deck maintenance but depends on a Windows host and consistent 5 GHz or wired connectivity for stability.
