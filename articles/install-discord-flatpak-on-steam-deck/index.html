Install Discord Flatpak on Steam Deck

By Brittany Coleman • Published January 25, 2026

This guide assumes SteamOS with Desktop Mode available, Flatpak support ready, and a network connection steady enough to fetch packages. You will hear the soft click of KDE windows, see the Discover store populate, and notice Discord’s login screen arrive without drama. If Flathub is not configured yet, we will add it safely, then install Discord, verify microphone input, and test push to talk so voice feels immediate and responsive.

Frequently asked questions

Discord is installed but there is no microphone input. What should I check first?

Select the intended input device in Discord settings, then confirm the mic shows activity in system sound settings. If the system does not detect it, replug or switch ports, then relaunch Discord and reselect the device.

Do I need extra Flatpak permissions for Discord to access audio?

Usually no. Discord detects PipeWire or ALSA devices by default. If inputs remain unavailable after system verification, adjust permissions conservatively using a permissions manager and retest. Avoid broad grants that are not necessary.

Discord will not launch after an update. How can I recover quickly?

Update Flatpak runtimes, reboot to restart the session, and try launching from a terminal to see errors. If needed, remove only Discord’s user config to reset settings, then reinstall the app while keeping the same user scope.

Should I install Discord for user or system scope on Steam Deck?

User scope is recommended for most people because it avoids system wide changes and keeps the app isolated per account. Use system scope only when multiple user accounts intentionally share the same installation.

Can I use push to talk in Gaming Mode with a controller?

Yes. Add Discord as a non game shortcut in Steam, then map a controller button to a keyboard key used for push to talk. Test the mapping in a private call and adjust sensitivity to avoid fan noise.
