Zero Trust Network Access

Access strategy that verifies identity and context for every session.

In detail

Zero Trust Network Access applies least privilege to wireless by mapping identity and device posture to granular policies. It reduces lateral movement by segmenting traffic and enforcing continuous verification.

Synonyms

ZTNA, Zero Trust

Abbreviations

ZTNA

Related terms

  • Network Segmentation
  • NAC
