File Structure

The organized folders used by the device and OS.

In detail

File structure refers to the folders and paths on the SD card that store ROMs, BIOS, saves, thumbnails, and configuration files. A consistent layout prevents errors and speeds navigation.

Synonyms

Folder layout, Directory structure

Abbreviations

FS

Related terms
