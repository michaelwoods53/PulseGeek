Recovery Mode

A special environment used to reset, update, or repair the system.

In detail

Recovery Mode is a bootable environment that enables actions like factory reset, cache wiping, and applying updates. It helps repair boot failures without loading the full operating system.

Synonyms

Android recovery

Abbreviations

REC
