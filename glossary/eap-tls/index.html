Extensible Authentication Protocol - TLS

An EAP method using certificates for mutual authentication.

In detail

EAP-TLS uses client and server certificates to establish a secure, phishing-resistant connection for Wi‑Fi access. It removes password risks and is widely recommended for enterprise WLANs.

Synonyms

certificate auth

Abbreviations

EAP-TLS

Related terms

  • 802.1X
  • WPA3-Enterprise
