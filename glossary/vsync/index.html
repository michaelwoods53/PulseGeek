VSync

A setting that aligns frame output with display refresh.

In detail

VSync synchronizes rendering to the monitor's refresh to avoid tearing. It can increase input latency if queues build up, and alternatives like G-SYNC or FreeSync may help.

Synonyms

vertical sync
