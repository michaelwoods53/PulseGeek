Differentiated Services Code Point

A header field used to mark packet priority.

In detail

DSCP markings classify traffic for QoS policies. While not all home routers enforce DSCP, mapping game streaming or UDP to higher classes can help Steam Deck sessions stay responsive.

Synonyms

dscp, diffserv

Abbreviations

DSCP
