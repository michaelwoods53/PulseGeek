Libretro Core

A plugin that emulates a specific system in RetroArch.

In detail

A Libretro core is a modular emulator that RetroArch loads for a specific console or handheld. Each core has its own options, performance profile, and compatibility on Miyoo Mini.

Synonyms

Emulator core, Core

Abbreviations

CORE
