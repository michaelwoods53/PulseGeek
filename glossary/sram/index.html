SRAM

Native in-game save data stored by the emulated system.

In detail

SRAM holds the game’s built-in save files, like battery saves in cartridges. It is smaller and more stable across cores than save states on Miyoo devices.

Synonyms

battery save

Abbreviations

SRAM
