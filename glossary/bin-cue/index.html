BIN/CUE

A disc image format pairing binary data with a cue sheet.

In detail

BIN/CUE images store PS1 disc data with a separate CUE file describing tracks. Correct CUE references are needed for audio tracks and accurate loading in DuckStation.

Synonyms

cue sheet images

Abbreviations

NONE
