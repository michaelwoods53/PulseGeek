Service Set Identifier

The public name of a Wi‑Fi network broadcast by an AP.

In detail

The SSID is a readable identifier that helps devices find and join a wireless network. Planning SSIDs affects roaming and band steering, especially in multi-AP deployments.

Synonyms

network name

Abbreviations

SSID
