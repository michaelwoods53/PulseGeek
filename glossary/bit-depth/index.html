Bit Depth

The number of bits used to represent each audio sample.

In detail

Bit depth influences noise floor and headroom. Lower bit depths reduce size but can increase noise or artifacts; careful dithering and compression mitigate issues.

Synonyms

resolution

Abbreviations

BD
