Bootloader

Software that initializes hardware and starts the operating system.

In detail

The bootloader runs at power-on, sets up hardware, and loads Onion OS. If corrupted, systems can fail to boot and may require reflashing.

Synonyms

boot manager

Abbreviations

BL
