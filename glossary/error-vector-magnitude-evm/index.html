Error Vector Magnitude (EVM)

A measure of the difference between ideal and received constellation points.

In detail

EVM quantifies modulation quality by comparing measured symbol vectors to ideal reference points. Lower EVM indicates better transmitter and receiver performance and supports higher‑order QAM.

Synonyms

modulation error

Abbreviations

EVM
