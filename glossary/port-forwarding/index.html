Port Forwarding

Manual router rules that send traffic to a specific device.

In detail

Port forwarding ensures inbound game traffic reaches the right console or PC. It can help achieve open NAT but needs correct ports and a static local address.

Synonyms

port mapping

Related terms

  • NAT
  • UPnP
  • Dynamic IP
