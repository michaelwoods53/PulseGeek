Per-Core Override

RetroArch settings saved for one core only.

In detail

A per-core override stores configuration specific to a Libretro core, such as video, audio, and input settings. On Miyoo, using per-core overrides ensures each system has tuned performance without affecting others.

Synonyms

core override

Abbreviations

PCO
