MCR File

A common PS1 memory card file format.

In detail

An MCR file is a virtual memory card format used by several emulators like ePSXe and RetroArch cores. DuckStation can often import MCR files directly or with conversion.

Synonyms

.mcr, ps1 mcr

Abbreviations

MCR

Related terms

  • ePSXe
  • RetroArch
