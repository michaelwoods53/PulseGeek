fsck

A Linux tool to check and repair filesystem errors.

In detail

fsck scans and fixes inconsistencies on filesystems like EXT4 and Btrfs. It is useful on Steam Deck when a microSD card becomes corrupted or won’t mount correctly.

Synonyms

file system check

Abbreviations

FSCK
