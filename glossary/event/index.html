Event

A trigger used to play or control audio in response to game actions.

In detail

An event is a named trigger that starts, stops, or modifies audio based on gameplay. Events connect code to sound assets and can carry parameters that shape playback, volume, pitch, or routing in real time.

Synonyms

audio event, sound trigger

Abbreviations

EVT
