Per-Core Options

Settings that apply only to a specific emulator core.

In detail

Per-core options allow different emulators to keep their own settings for controls, video, and performance. On Miyoo Mini, this prevents conflicts between systems.

Synonyms

Core options, Core settings

Abbreviations

PCO
