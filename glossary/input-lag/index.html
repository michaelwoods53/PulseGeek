Input Lag

The delay between a control input and the on-screen response.

In detail

Input lag affects how responsive games feel on a TV or monitor. On Steam Deck, settings like Game Mode, VRR, and wired controllers can help reduce lag.

Synonyms

latency, response delay

Abbreviations

LAG
