DNS over TLS

A protocol that encrypts DNS queries for privacy.

In detail

DNS over TLS protects DNS lookups from eavesdropping. It can add slight overhead; testing helps decide if the privacy benefit affects Steam Deck connection times.

Synonyms

dot, encrypted dns

Abbreviations

DOT
