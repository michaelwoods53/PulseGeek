User Datagram Protocol

A low-latency, connectionless transport often used in games.

In detail

UDP sends packets without handshakes, reducing overhead and latency. Many games use it for real-time actions where speed matters more than reliability.

Synonyms

udp protocol

Abbreviations

UDP
