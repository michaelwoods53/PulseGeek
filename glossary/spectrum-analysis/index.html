Spectrum Analysis

Measuring RF energy across frequencies to find interference.

In detail

Spectrum analysis reveals non‑Wi‑Fi interference, duty cycles, and channel occupancy. These insights help tune OBSS-PD, choose channels, and set RU sizes for reliable OFDMA scheduling.
