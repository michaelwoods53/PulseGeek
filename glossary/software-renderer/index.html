Software Renderer

A CPU-based renderer used when GPU backends fail.

In detail

The software renderer draws frames on the CPU and can bypass driver issues. It is slower but helpful for debugging or when Vulkan/OpenGL crash in DuckStation.

Synonyms

cpu renderer

Abbreviations

NONE
