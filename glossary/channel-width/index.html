Channel Width

The configured size of a Wi‑Fi channel such as 80, 160, or 320 MHz.

In detail

Channel width defines the total spectrum used by an AP. Puncturing allows most of a wide channel to be used while avoiding interfered slices, preserving capacity when conditions are imperfect.

Synonyms

bandwidth setting

Abbreviations

CW
