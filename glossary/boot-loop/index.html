Boot Loop

A device that restarts repeatedly without loading the OS.

In detail

A boot loop can occur after a failed firmware or OS update. Recovery steps on Miyoo Mini include restoring backups, re-flashing system files, or replacing a corrupted SD card.

Synonyms

Restart loop
