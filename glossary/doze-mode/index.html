Doze Mode

A low‑power state with limited radio and CPU activity.

In detail

Doze mode minimizes energy use by suspending most radio activity and scheduling periodic maintenance windows. It pairs with Wi‑Fi features like TWT to align wakeups with network traffic.

Synonyms

sleep mode, deep sleep

Abbreviations

DOZE
