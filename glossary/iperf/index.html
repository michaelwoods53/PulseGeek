Iperf

A tool to generate traffic and measure performance.

In detail

Iperf creates controlled TCP or UDP flows to test bandwidth, loss, and jitter. UDP mode is useful for assessing real-time behavior over Wi‑Fi.

Synonyms

throughput tester

Abbreviations

IPERF

Related terms

  • Ping
  • Goodput
  • Packet Loss
