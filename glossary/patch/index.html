Patch

Applies changes to ROMs like translations or fixes.

In detail

Patches using formats such as IPS or BPS modify ROM content for fixes, translations, or hacks. RetroArch on Miyoo can auto-apply patches if named correctly or configured in core options.

Synonyms

IPS patch, BPS patch

Abbreviations

PATCH
