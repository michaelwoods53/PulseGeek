Steam Deck

Valve’s handheld gaming PC running SteamOS with an AMD APU.

In detail

Steam Deck is Valve’s handheld gaming PC that runs SteamOS. It uses an AMD APU combining CPU and GPU. Users can adjust software settings like TDP, FPS caps, and refresh rate to balance performance, heat, battery life, and fan noise.
