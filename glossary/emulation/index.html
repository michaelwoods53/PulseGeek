Emulation

Software that reproduces the behavior of hardware or a system.

In detail

Emulation is the process of using software to mimic the behavior of hardware, operating systems, or consoles so software written for the original system can run. It relies on accurate timing, instruction handling, and device models.

Synonyms

system emulation, console emulation
