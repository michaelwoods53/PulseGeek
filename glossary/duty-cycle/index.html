Duty Cycle

The fraction of time a device’s radio is awake and active.

In detail

Duty cycle is a key efficiency metric. Lowering active time through batching and scheduled wakeups extends battery life while maintaining required performance for the application.

Synonyms

radio on-time, active ratio

Abbreviations

DC
