DHCP

Automatically assigns IP addresses to devices on the network.

In detail

DHCP manages addresses and network settings like DNS and gateway. Correct lease ranges and reservations can make the Steam Deck’s connectivity more predictable and stable.

Synonyms

dynamic host configuration protocol

Abbreviations

DHCP
