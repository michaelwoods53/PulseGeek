Pairing mode

The state where a device is ready to connect over Bluetooth.

In detail

Headphones and earbuds enter pairing mode so the Steam Deck can discover and connect to them. Each brand has a different button sequence and timing to enable this mode.

Synonyms

discoverable mode, Bluetooth pairing
