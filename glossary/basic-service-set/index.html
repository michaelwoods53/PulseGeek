Basic Service Set

A single AP’s coverage area and associated clients.

In detail

The Basic Service Set represents the radio cell formed by one AP and its clients. Overlapping BSS areas and channel reuse must be planned to reduce interference and improve roaming.

Synonyms

bss cell

Abbreviations

BSS
