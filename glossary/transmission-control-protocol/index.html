Transmission Control Protocol

A reliable, connection-oriented transport protocol.

In detail

TCP guarantees ordered delivery by retransmitting lost packets, which adds latency. It is less common for real-time gameplay but used for some control traffic.

Synonyms

tcp protocol

Abbreviations

TCP
