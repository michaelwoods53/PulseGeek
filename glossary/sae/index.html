SAE

Peer‑to‑peer handshake used by WPA3‑Personal to resist password guessing.

In detail

Simultaneous Authentication of Equals (SAE) is a password‑authenticated key exchange used in WPA3‑Personal. It resists offline dictionary attacks by deriving keys in a way that requires active interaction for each guess and supports forward secrecy.

Synonyms

Dragonfly handshake

Abbreviations

SAE
