Patch (IPS/BPS)

A file that modifies a ROM without distributing copyrighted data.

In detail

IPS and BPS patches contain differences that can be applied to a ROM you own, enabling translations or fixes without sharing the original copyrighted content.

Synonyms

rom patch

Abbreviations

IPS, BPS
