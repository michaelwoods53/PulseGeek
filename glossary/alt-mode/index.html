Alt Mode

A USB-C feature that allows video signals like DisplayPort to pass through.

In detail

Alt Mode enables non-USB protocols over USB-C, such as DisplayPort. This lets the Steam Deck send video to external displays through a compatible dock or adapter.

Synonyms

USB-C Alt Mode, DisplayPort Alt Mode

Abbreviations

ALT

Related terms

  • USB-C
  • DisplayPort
  • HDMI
