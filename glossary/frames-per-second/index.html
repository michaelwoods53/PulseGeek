Frames Per Second

The number of images shown each second in a game.

In detail

Frames Per Second measures how many frames your system renders each second. Higher FPS makes motion look smoother and reduces input latency, but it depends on GPU, CPU, and settings.

Synonyms

frame rate

Abbreviations

FPS

Related terms

  • VSync
  • Variable Refresh Rate
