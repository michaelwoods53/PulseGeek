Pre-Shared Key

A shared passphrase used by multiple devices for Wi‑Fi access.

In detail

PSK uses a common passphrase for network access. While easy to deploy, it poses risks for large IoT fleets due to key sharing and weak revocation, making certificate-based methods preferable for security.
