TV Game Mode

A TV preset that reduces processing to lower input lag.

In detail

Game Mode disables post-processing on TVs to reduce latency. When using the Steam Deck on a TV, enabling Game Mode helps achieve sharper control response.

Synonyms

low latency mode, ALLM

Abbreviations

GAME
