End-to-End Latency

Total delay from source to destination and back if RTT.

In detail

End-to-end latency includes encode/decode, queueing, transmission, and processing across the entire path. It is the metric users feel in real-time apps.

Synonyms

e2e latency

Abbreviations

E2E
