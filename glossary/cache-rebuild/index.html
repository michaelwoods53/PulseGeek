Cache Rebuild

Refreshing stored data to fix display or speed issues.

In detail

Rebuilding caches forces Onion OS to rescan files and regenerate thumbnails or lists. It can fix missing artwork and menu glitches after changes.

Synonyms

rebuild cache, refresh cache

Abbreviations

CACHE
