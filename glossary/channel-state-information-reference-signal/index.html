Channel State Information Reference Signal

Known signals used to estimate the channel for CSI.

In detail

CSI reference signals or sounding frames help receivers estimate the channel response across subcarriers and antennas. Accurate CSI enables beamforming and MU scheduling.

Synonyms

sounding, csi-rs

Abbreviations

CSI-RS
