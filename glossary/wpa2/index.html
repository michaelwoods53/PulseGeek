WPA2

A common Wi‑Fi security protocol that is widely supported but older than WPA3.

In detail

WPA2 uses AES encryption and has been the default for many years. It remains widely compatible, but WPA3 is preferred when available for stronger protection.

Synonyms

Wi‑Fi Protected Access 2

Abbreviations

WPA2
