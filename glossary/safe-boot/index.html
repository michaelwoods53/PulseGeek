Safe Boot

A minimal start mode used to troubleshoot system problems.

In detail

Safe boot loads only essential components so you can fix settings or files. On Onion OS, it helps recover from bad configs or incompatible updates.

Synonyms

recovery mode, safe mode

Abbreviations

SAFE

Related terms

  • Boot Loop
  • Rollback
  • Backup Image
