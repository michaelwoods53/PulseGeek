MCD File

A DuckStation memory card file extension.

In detail

MCD files are virtual memory cards used by DuckStation. They store in-game save blocks and can be backed up, synced, or converted to other formats with tools.

Synonyms

.mcd, duckstation mcd

Abbreviations

MCD
