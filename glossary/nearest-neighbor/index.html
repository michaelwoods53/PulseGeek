Nearest Neighbor

A fast scaling method that preserves sharp edges.

In detail

Nearest neighbor scaling maps each output pixel to the closest input pixel. It keeps sharp pixels but can produce jaggies or shimmering during motion.

Synonyms

point sampling

Related terms
