Per-Game Override

RetroArch settings saved for a single game.

In detail

A per-game override applies a configuration only when a specific game is launched. It is useful for titles that need unique frame pacing, audio, or input settings on Miyoo handhelds.

Synonyms

game override

Abbreviations
