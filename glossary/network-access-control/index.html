Network Access Control

Policy-based control that allows, blocks, or quarantines devices.

In detail

NAC evaluates device identity and posture to decide access levels on the network. Integrated with 802.1X and directory services, it can assign VLANs, roles, or microsegmentation policies for Wi‑Fi clients.

Synonyms

nac

Abbreviations

NAC

Related terms

  • 802.1X
  • Role-Based Access Control
  • Zero Trust Network
