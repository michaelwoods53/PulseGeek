Deterministic Latency

Latency that is controlled within predictable bounds for time‑critical traffic.

In detail

Deterministic latency aims to deliver packets within tight time windows, reducing jitter. Wi‑Fi 7 features such as improved scheduling and MLO help approach deterministic performance for select flows.

Synonyms

Bounded latency, Predictable latency

Abbreviations

DLAT

Related terms

  • Time-Sensitive Networking
  • QoS
  • Multi‑Link Operation
