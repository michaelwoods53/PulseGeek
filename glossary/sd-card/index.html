SD Card

Removable storage used by Miyoo Mini.

In detail

An SD card stores the operating system, ROMs, BIOS files, saves, and media on Miyoo Mini. Capacity, speed class, and file system format affect performance and reliability.

Synonyms

microSD, memory card
