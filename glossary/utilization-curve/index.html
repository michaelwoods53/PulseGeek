Utilization Curve

Graph showing load versus performance.

In detail

A utilization curve plots network load against key metrics like throughput, latency, or packet loss. It helps identify the knee of the curve where added load sharply degrades performance.

Synonyms

airtime curve, throughput curve

Abbreviations

UTC

Related terms

  • Airtime Utilization
  • Service Level Agreement
  • Throughput
