Filesystem

The method an OS uses to organize data on storage devices.

In detail

A filesystem defines how files are stored, named, and accessed on media like microSD cards. Steam Deck supports filesystems such as exFAT, EXT4, and Btrfs for libraries and game data.

Synonyms

file system

Abbreviations

FS

Related terms

  • exFAT
  • EXT4
  • Btrfs
