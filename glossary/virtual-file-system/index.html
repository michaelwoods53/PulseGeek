Virtual File System

A system that maps mod files into the game without copying them directly.

In detail

A virtual file system lets a mod manager present staged mod files to a game at runtime. It reduces clutter, preserves the base game files, and supports profiles and quick enable or disable actions.

VFS

Abbreviations
