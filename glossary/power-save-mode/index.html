Power Save Mode

A client state where the radio sleeps and wakes to check for buffered frames.

In detail

Power Save Mode lets stations sleep to reduce energy use, waking periodically based on DTIM or listen intervals. It works with features like U‑APSD and TWT to align wakeups with actual traffic.

Synonyms

wifi ps mode, psm

Abbreviations

PS

Related terms

  • DTIM
  • Listen Interval
  • PS‑Poll
