Network Address Translation

The process of mapping private addresses to public ones.

In detail

NAT enables multiple devices to share one public IP. For gaming, restrictive NAT types can block connections or increase setup latency for peer-to-peer matches.

Synonyms

nat type

Abbreviations

NAT

Related terms

  • Port Forwarding
  • Dynamic IP
