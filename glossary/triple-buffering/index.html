Triple Buffering

Uses an extra buffer to smooth frames.

In detail

Triple buffering keeps an additional frame in the queue to reduce tearing, which can smooth video but may add latency. On Miyoo, it is used selectively based on the core and game.

Synonyms

triple buffer

Abbreviations

TB
