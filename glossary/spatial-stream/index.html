Spatial Stream

An independent data stream sent over MIMO.

In detail

A spatial stream is an independent data path transmitted simultaneously using multiple antennas. The number of spatial streams scales peak throughput for capable devices.

Synonyms

mimo stream

Abbreviations

SS

Related terms

  • Multiple-Input Multiple-Output
  • Beamforming
