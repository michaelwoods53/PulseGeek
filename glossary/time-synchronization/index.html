Time Synchronization

Keeping the device clock accurate with network time.

In detail

Some online services reject connections from devices with large clock drift. Ensuring Steam Deck time sync via NTP can resolve login and matchmaking errors.

Synonyms

system clock sync

Abbreviations

NTP
