A2 rating

A performance class that improves random I/O and IOPS for apps and games.

In detail

A2 is an SD card performance class designed for faster random reads and writes, which helps with launching apps and loading game assets from microSD on devices like the Steam Deck.

Synonyms

app performance class 2
