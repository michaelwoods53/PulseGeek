Dual Boot

Running two operating systems on the same device.

In detail

Dual boot lets users keep stock firmware while using Onion OS. It can help with testing updates and provides a fallback if Onion OS fails.

Synonyms

two-boot setup, multi-boot

Abbreviations

DB
