Cycle Count

The number of full charge and discharge cycles.

In detail

Cycle count tracks how many full cycles a battery has undergone. Higher cycle counts correlate with wear, so monitoring cycles on Steam Deck helps estimate remaining battery health.

Synonyms

charge cycles, battery cycles

Abbreviations

CC
