Zigbee

A low-power mesh protocol used for lighting control networks.

In detail

Zigbee enables pole-to-pole mesh networking with short-range radios. It is common in neighborhood-scale lighting deployments where dense nodes create a robust mesh.

Synonyms

ieee 802.15.4 mesh, zigbee mesh

Related terms

  • LoRaWAN
  • NB-IoT
