Performance Preset

A set of settings optimized for speed or quality.

In detail

Performance presets balance frame rate, audio, and visuals. On Onion OS, choosing lighter shaders and cores improves stability on low-power chips.

Synonyms

tuning profile, speed preset

Abbreviations
