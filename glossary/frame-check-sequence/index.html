Frame Check Sequence

A checksum used to detect frame errors.

In detail

The frame check sequence is a cyclic redundancy check appended to frames to detect errors that survive PHY‑layer decoding, triggering retransmissions at higher layers.

Synonyms

fcs, crc

Abbreviations

FCS

Related terms

  • Bit Error Rate
  • Automatic Repeat Request
