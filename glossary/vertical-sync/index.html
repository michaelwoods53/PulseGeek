Vertical Sync

A setting that synchronizes frame output to display refresh.

In detail

Vertical Sync matches the game’s frames to the monitor’s refresh to prevent tearing. It can add input lag and cause stutter if frame rate drops below the refresh rate.

Synonyms

vsync

Abbreviations

VSYNC

Related terms

  • Frames Per Second
  • G-SYNC
