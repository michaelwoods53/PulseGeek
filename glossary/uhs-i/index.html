UHS-I

A bus interface for SD cards that sets maximum transfer speeds.

In detail

UHS-I is a speed interface for SD cards that enables faster read and write performance than older standards. Steam Deck supports UHS-I cards, which are common and cost-effective for game storage.

Synonyms

ultra high speed i

Abbreviations

UHS-I
