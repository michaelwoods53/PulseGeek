FAT32

A file system commonly used for compatibility on SD cards.

In detail

FAT32 is widely supported by devices and firmware. Many Onion OS setups use FAT32 partitions for ROMs and saves due to compatibility.

Synonyms

fat file system

Abbreviations

FAT32
