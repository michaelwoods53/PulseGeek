High-Level Emulation BIOS

A software recreation of the PS1 BIOS that avoids requiring a BIOS dump.

In detail

HLE BIOS simulates BIOS behavior without an original dump. It can boot many games but may have compatibility differences. DuckStation allows switching between HLE and real BIOS per game.

Synonyms

emulated bios

Abbreviations

HLE
