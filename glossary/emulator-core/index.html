Emulator Core

The component that emulates a specific system.

In detail

An emulator core is the module that implements the logic to emulate a particular console or platform. Frontends can load different cores to run different systems under a common interface.

Synonyms

core, plugin core

Related terms

  • Frontend
  • Low-Level Emulation
