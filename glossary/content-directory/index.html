Content Directory

A folder path where emulators scan for games.

In detail

Content directories are the structured folders that hold personal backups. Consistent paths enable playlist generation, scraping, and easy migration to new storage.

Synonyms

rom directory, games folder

Abbreviations

CDIR

Related terms

  • Playlist
  • RetroArch
  • Gamelist XML
