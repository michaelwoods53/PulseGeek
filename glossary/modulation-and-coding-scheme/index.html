Modulation and Coding Scheme

An index pairing of modulation order and coding rate.

In detail

MCS indexes define combinations of modulation order and coding rate used by Wi‑Fi. Devices adapt MCS to match channel quality, balancing throughput and reliability.

Synonyms

rate index

Abbreviations

MCS
