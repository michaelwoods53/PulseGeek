Beacon Interval

The time between AP beacon transmissions.

In detail

Beacon Interval sets the cadence for management frames that announce network parameters. It interacts with DTIM and listen interval to influence client wakeups and battery use.

Synonyms

wifi beacon period, bi

Abbreviations

BI

Related terms

  • DTIM
  • Listen Interval
  • Power Save Mode
