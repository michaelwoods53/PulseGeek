M3U Playlist

A simple text playlist format referencing multiple files.

In detail

An M3U playlist lists file paths and is useful for multi-disc games, enabling smooth disc swapping in emulators like RetroArch without renaming or merging disc images.

Synonyms

m3u file

Abbreviations

M3U
