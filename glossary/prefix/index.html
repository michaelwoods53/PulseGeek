Prefix

A folder that acts as a fake Windows install for a game.

In detail

A Proton or Wine prefix contains the virtual Windows filesystem and registry for an app. Editing or recreating a prefix can fix corruption or dependency problems on Steam Deck.

Synonyms

Wine prefix, Proton prefix

Abbreviations

PREFIX
