Retroid Launcher

The stock game launcher and interface for Retroid Pocket devices.

In detail

Retroid Launcher is a front end that organizes games, provides scraping for artwork, and launches emulator apps. It integrates with Android settings and can be customized for navigation, input, and visuals.
