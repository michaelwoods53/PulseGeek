Pairwise Master Key

Key material used to derive session encryption keys.

In detail

The PMK is established via SAE or EAP methods and underpins secure data exchange. Correct caching and handling improve roaming security in Wi‑Fi 7.

Synonyms

master session key

Abbreviations

PMK

Related terms

  • PMKID
  • SAE
  • EAP‑TLS
