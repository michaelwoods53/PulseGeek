mkfs

A command to create a filesystem on a device or partition.

In detail

mkfs initializes a filesystem such as EXT4 or Btrfs on a target device. On Steam Deck, it is used in Desktop Mode to format microSD cards via terminal.

Synonyms

make filesystem

Abbreviations

MKFS
