Path Loss

The reduction in signal strength as it travels from AP to client.

In detail

Path loss depends on distance, frequency, and obstacles. Floor plans should account for wall types, elevation, and material attenuation to predict path loss accurately.

Synonyms

signal loss

Abbreviations

PATHLOSS
