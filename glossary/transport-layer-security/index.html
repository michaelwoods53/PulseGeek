Transport Layer Security

A protocol that secures data in transit.

In detail

TLS provides encryption and authentication for application protocols like MQTT and HTTPS. Features such as session resumption reduce handshake overhead for frequently connecting IoT devices.

TLS

Abbreviations

TLS
