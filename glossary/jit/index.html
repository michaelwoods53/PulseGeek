JIT

Compiles code at runtime for a balance of speed and flexibility.

In detail

JIT compilation translates code segments to native instructions as needed, offering speed advantages with some overhead. Many emulators use JIT for CPU or GPU translation.

Synonyms

just-in-time compiler

Abbreviations

JIT

Related terms

  • Dynarec
  • Interpreter
