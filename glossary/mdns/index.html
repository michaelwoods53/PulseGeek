mDNS

Local name resolution without a central server.

In detail

mDNS allows devices to discover each other on the same network using multicast. Onion OS can advertise hostnames so clients connect without knowing IPs.

Synonyms

multicast dns, Bonjour

Abbreviations

MDNS

Related terms

  • DNS
  • Onion OS
  • Hostname
