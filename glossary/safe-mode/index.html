Safe mode

A reduced startup mode for troubleshooting.

In detail

Safe mode starts the system with minimal services and default settings, useful for undoing broken configurations or preparing a clean firmware reinstall.

Synonyms

recovery mode

Abbreviations

SM

Related terms

  • Factory reset
  • Boot loop
