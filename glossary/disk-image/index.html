Disk Image

A file that contains the full contents of a storage device or partition.

In detail

A disk image is a byte-for-byte copy of a storage device or partition. For Onion OS, the image is written to a microSD card to create a bootable setup.

Synonyms

os image

Abbreviations

IMG

Related terms

  • Checksum
  • Flash Utility
  • microSD Card
