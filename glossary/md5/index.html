MD5

A 128-bit hash function used for file verification.

In detail

MD5 produces a fixed-size hash used to check that BIOS, firmware, or game images match known references. It is fast but weaker than modern options for security.

Synonyms

md5 checksum

Abbreviations

MD5

Related terms
