Proton

Valve’s Windows-to-Linux compatibility layer used on Steam Deck.

In detail

Proton combines Wine, DXVK, and other components to run Windows games on Linux. Different Proton builds can affect anti-cheat initialization and network behavior, making version choice important for online games on Steam Deck.
