Extensible Authentication Protocol

Framework for network access authentication used in enterprise Wi‑Fi.

In detail

EAP supports multiple authentication methods under 802.1X for secure network access. Wi‑Fi 7 enterprise deployments commonly use EAP‑TLS or similar mechanisms with WPA3‑Enterprise.

Synonyms

EAP, 802.1X authentication

Abbreviations

EAP
