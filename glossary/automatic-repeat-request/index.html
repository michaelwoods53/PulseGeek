Automatic Repeat Request

A protocol that requests retransmission of failed frames.

In detail

ARQ uses acknowledgments and timeouts to trigger retransmission of frames detected in error. It complements FEC to achieve target reliability in Wi‑Fi networks.

Synonyms

arq, retransmission

Abbreviations

ARQ
