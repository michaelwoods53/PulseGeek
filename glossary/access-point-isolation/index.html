Access Point Isolation

A setting that prevents Wi‑Fi clients from talking to each other.

In detail

AP isolation improves security on guest networks but can block local streaming or file access. Disabling it on the main SSID may be needed for Steam Deck remote play across LAN devices.

Synonyms

ap isolation, client isolation

Abbreviations

NA
