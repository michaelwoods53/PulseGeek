Cloud Sync

Keeping files the same across devices using cloud storage.

In detail

Cloud sync uses services like Google Drive, Dropbox, or OneDrive to keep DuckStation saves up to date on multiple devices. Proper folder mapping reduces conflicts and accidental overwrites.
