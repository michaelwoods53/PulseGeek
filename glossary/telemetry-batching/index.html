Telemetry Batching

Collecting events and sending them in bursts to reduce wakeups.

In detail

Telemetry batching groups sensor readings or logs into scheduled transmissions that match wake windows. This reduces radio on‑time and overhead per message, improving energy efficiency.

Synonyms

data batching, event batching

Abbreviations

TB

  • Duty Cycle
  • Target Wake Time
