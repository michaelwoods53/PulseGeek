Simultaneous Authentication of Equals

A password-based key exchange used in WPA3-Personal.

In detail

SAE is a secure password-authenticated key exchange that replaces WPA2-PSK. For IoT, SAE can be used where certificate-based authentication is not feasible, though enterprises often prefer EAP‑TLS.

Synonyms

WPA3 SAE

Abbreviations

SAE

Related terms

  • WPA3 Enterprise
  • Pre-Shared Key
  • EAP‑TLS
