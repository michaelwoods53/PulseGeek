Per‑Game Profile

Saved settings applied to a specific game.

In detail

A per‑game profile stores FPS caps, refresh rate, TDP, and other options for a single title. It enables quick switching between cool-and-quiet settings tailored to each game on the Steam Deck.

Synonyms

game profile, title-specific profile

Abbreviations

PGP

Related terms

  • FPS Cap
  • Refresh Rate
  • PowerTools
