Hybrid Automatic Repeat Request

Retransmission method combining error correction and repeats to improve reliability.

In detail

HARQ improves link reliability by combining forward error correction with selective retransmissions. In Wi‑Fi 7, it helps maintain throughput under variable channel conditions and reduces latency spikes.

Synonyms

HARQ, Hybrid ARQ

Abbreviations

HARQ
