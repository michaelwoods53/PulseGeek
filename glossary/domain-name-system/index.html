Domain Name System

Translates hostnames to IP addresses.

In detail

DNS affects how fast connections start. Using reliable DNS resolvers and clearing caches can reduce connection errors and speed up services the Steam Deck uses for online play and streaming.

Synonyms

dns, name resolution

Abbreviations

DNS
