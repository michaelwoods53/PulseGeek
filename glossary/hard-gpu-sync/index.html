Hard GPU Sync

A method that forces the CPU to wait for GPU work to lower lag.

In detail

Hard GPU sync reduces queuing by synchronizing the CPU and GPU more tightly. It can lower latency but may reduce throughput and cause performance drops.

Synonyms

gpu hard sync
