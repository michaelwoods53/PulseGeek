Gaming Mode

The console-like interface for launching and managing games on the Deck.

In detail

Gaming Mode is the default Steam Deck interface for playing games. It offers quick access to performance overlays, power profiles, and display settings for docked play.

Synonyms

Steam Game Mode, console UI
