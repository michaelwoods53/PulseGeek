Emulator

Software that imitates console hardware to run games on other systems.

In detail

Emulators enable practice features like savestates and frame advance and can be used for runs if allowed. Rules vary by game on versions, settings, and input devices.

Synonyms

emu

Abbreviations

EMU

Related terms

  • Savestate
  • Frame Advance
  • Verification
