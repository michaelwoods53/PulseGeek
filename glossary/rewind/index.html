Rewind

A feature that lets players reverse gameplay by seconds.

In detail

Rewind buffers states in memory so you can step back during gameplay. On Miyoo, it increases CPU and memory usage; many users disable it for better performance.

Synonyms

retroarch rewind

Abbreviations

RWD

Related terms
